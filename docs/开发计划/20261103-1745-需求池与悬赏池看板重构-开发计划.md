## 一、背景

需求池页现在有列表/看板两个视图，看板是自研的 `RoadmapBoard.vue`：六列压成四列、卡片信息靠文字堆叠，视觉与站内其它页面没有统一语言。悬赏页是「英雄区 + 等级表格 + 四步流程条 + 表单 + 查询」的长页面，流程条只是四个并列方块。

目标是把 beui 的 kanban-board 版式搬过来：发丝线卡片、胶囊筛选、列内滚动渐隐、悬停反馈、清晰的列头计数，同时保持 VitePress 现有 token、中英文双语、深浅色主题，不引入 React / Tailwind / motion 任何依赖。

## 二、组件解剖

`kanban-board` 由七个文件构成：

| 文件 | 作用 |
| --- | --- |
| `types.ts` | 任务、列、成员、优先级的数据形状 |
| `kanban-board.tsx` | 壳体：标题与计数、主操作按钮、筛选胶囊、搜索框、列容器、拖拽编排、弹窗、a11y 播报 |
| `board-column.tsx` | 单列：图标圆徽 + 标题 + 等宽数字计数 + 重命名/加任务按钮 + 列内滚动与上下渐隐蒙版 |
| `task-card.tsx` | 卡片：标题、一行描述、标签行、分隔线、底部 chip（优先级 / 负责人 / 日期） |
| `task-dialog.tsx` | 新建与编辑弹窗：标题、描述、状态、优先级、负责人、日期、清单 |
| `use-board-drag.ts` | 指针拖拽：6px 阈值、触摸 200ms 长按、边缘自动滚动、放置点判定、Esc 取消、点击抑制 |
| `board-utils.ts` | 焦点环样式、优先级枚举、保持过滤外条目相对顺序的移动算法 |

值得照搬的交互：列头「图标 + 标题 + 数字」三段式；卡片底部 chip 横排；列体滚动到顶/底时渐隐（`mask-image`）；筛选胶囊的 roving tabindex 与方向键切换；空态虚线框；`aria-live` 播报筛选结果与操作结果。

不照搬的部分：整套拖拽换列、列重命名、新建任务弹窗、负责人头像、motion 弹簧动画。

## 三、适配决策

### 需求池

| beui 能力 | 本站做法 | 原因 |
| --- | --- | --- |
| 拖动卡片换列 | 不做 | 状态由管理员在后台改，读者拖了也无法落地，会变成「拖完又弹回去」的假交互 |
| 列重命名 / 列内加任务 | 不做 | 列是固定的状态归并组，不是用户数据 |
| 优先级 chip | 换成「类型 · 分类 · 投票 · 评论」chip | 需求没有优先级字段 |
| 负责人头像 | 不做 | 无公开负责人字段 |
| 筛选胶囊 | 保留，语义改为「类型筛选」（全部/功能建议/缺陷/改进/咨询） | 列已经是状态，胶囊再筛状态会自相矛盾 |
| 搜索框 | 保留，本地即时过滤 | 当前只在回车时打请求，体感慢 |
| 列内滚动 + 渐隐 | 照搬 | 100 条数据必须限制列高 |
| 方向键 | 改为在列内/跨列移动焦点，不移动卡片 | 无写权限 |
| 弹窗 | 继续用现有 `FeedbackForm` 弹窗 | 字段远比 beui 的多（类型、分类、版本、悬赏意向） |

### Bug 悬赏池

公开接口只有 `policy` / `stats` / `lookup`（编号 + 邮箱查单条），**没有任何公开列表**，因此不做真实提交记录的看板——那需要新增后端端点并另行部署，超出本次范围，且涉及提交内容公开的隐私口径。

做法是把页面里已有的「四步流程」升级为同款看板：四列 = 提交报告 / 审核评估 / 定级发放 / 结案归档，卡片是该阶段的具体要点。数值一律从 `/bounty/policy` 读取（SLA 小时数、等级金额、有效性系数），不写死。英雄区、等级表、表单、查询保持功能不变，只统一卡片与胶囊的视觉语言。

## 六、视觉与交互规格

- 列宽 `minmax(17rem, 1fr)`，列间距 12px；桌面横向滚动，窄屏 `scroll-snap`。
- 看板列体最大高度 `min(62vh, 560px)`，超出列内滚动；顶部/底部各 20px 渐隐。
- 卡片：16px 圆角、1px 发丝线、内边距 16px；悬停边框转品牌色 + 轻微阴影，150ms。
- 底部 chip：28px 高、全圆角、1px 边框，字号 12px。
- 胶囊：32px 高、全圆角；选中态实底，未选中透明。
- 动效只做 120–180ms 的 opacity / border / transform，`prefers-reduced-motion` 下全部关闭。
- 断点沿用页面现有口径：≥1024 两栏（池 + 动态），768–1024 单栏，<768 默认列表视图。
- a11y：卡片为 `button` 语义、可见焦点环、`aria-label` 带标题；胶囊 `role="tab"` + 方向键；筛选结果写入 `aria-live`；列体 `aria-label` 带标题与数量。

## 十一、范围修订（2026-11-03 18:40）

第一版只换了看板，用户反馈「跟优化前差不多」，要求「把里面的组件全部重构掉，用这个新的组件库」。据此把范围扩大为**整页组件重构**：

### 新增组件库层

`.vitepress/theme/components/ui/`

| 文件 | 说明 |
| --- | --- |
| `ui.css` | token 层：`--ui-radius-card/field/pill`、`--ui-fg*`、`--ui-border(-strong)`、`--ui-accent(-soft)`、`--ui-ring`、阴影；全部映射到 `--vp-c-*`，深浅色自动跟随 |
| `UiButton.vue` | 胶囊按钮，primary / outline / ghost / subtle 四态，`href` 时渲染 `<a>` |
| `UiInput.vue` | 36px 高、12px 圆角输入框，左右图标插槽 |
| `UiTabs.vue` | 胶囊分段控件，roving tabindex + 方向键 |
| `UiChip.vue` | 26px 小胶囊（替代 `KanbanChip`） |
| `UiModal.vue` | 弹窗外壳：遮罩、16px 圆角、头/身/脚三段、Esc 关闭、滚动锁 |
| `UiStat.vue` | 统计卡（大数字 + 标签 + 状态色点） |

### 页面重写

- 需求池：页头改成「眉标 + 大标题 + 副文案 + 胶囊按钮」，新增四格统计条（总数 / 总票数 / 处理中 / 已完成），视图切换换成胶囊分段，列表行换成 16px 圆角发丝线卡片，筛选行补回「状态 / 类型 / 排序」文字标签，提交弹窗换成 `UiModal`；删除 `RoadmapBoard.vue`。

### 实测修正

- 窄屏溢出：`.feedback-page-body` 断点里 `1fr` 的最小值是 min-content，筛选行会把整列撑出视口，改为 `minmax(0, 1fr)`。
- 看板列体是纵向 flex，子项默认允许压缩会把卡片挤扁，补 `flex-shrink: 0`；列高统一靠 `height: 100%` + `flex: 1`。
- 卡片底栏放不下「投票 + 评论 + 日期 + 编号」四项，日期移到 meta 行，编号保留在底栏右对齐。
- 统计卡的状态点原在数字上方，导致有/无点的卡片数字错位，改为跟在标签前。

### 横向溢出排查与修复（2026-11-03 19:20）

实测读数（`documentElement.scrollWidth` 与每个元素 `right > innerWidth`）：

| 宽度 | 现象 | 根因 | 修法 |
| --- | --- | --- | --- |
| 390 | 导航右侧内容组到 396，汉堡被挤出屏幕 | 品牌文字 124 + 图标组 178 > 容器 319 | ≤420px 隐藏 `.VPNavBarTitle .title > span`，只留 30px 图标 |
| 768 | 内容组到 867，溢出 99px | VitePress 768 就切桌面菜单，本站 7 个菜单项 479 + 仓库入口 66 + 搜索 36 + 更多浮层 44 放不下 | 汉堡模式从 768 延到 1024（菜单与「更多」收起，`VPNavScreen` 只在打开时渲染，强制显示无副作用） |
| 960–1024 | 内容组到 1031，英文页溢出 23px | 160px 搜索框空壳在 ≥960 出现 + 英文菜单更宽 | 192px 文字化搜索框的断点从 960 提到 1280，更窄时退回图标按钮（仍打开同一弹窗） |
| 360 | 悬赏表单 `fieldset.form-section` 到 378 | `<fieldset>` 的 UA 默认 `min-width: min-content` | `.form-section { min-width: 0 }` |
| 420–1440 | 无溢出 | — | — |

扫描覆盖 360 / 390 / 420 / 600 / 768 / 900 / 959 / 960 / 1023 / 1024 / 1100 / 1200 / 1280 / 1440，中英两页各一遍，全部无元素越过视口；960 宽度下点汉堡能正常展开全屏菜单（8 个链接 + 语言 + 外观 + 搜索）。
