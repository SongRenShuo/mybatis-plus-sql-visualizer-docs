### 1.3 其他过期点（顺带修正）

- features/jpa-preview.md 已知边界「`findAllById`（IN 展开）暂未支持」已过期（dev 已支持）
- features/code-completion.md 两行与源码不符（上轮遗留待确认项，本次已核实）：`#{}` 参数名实为**方法参数名**（`@Param` 值优先 + param1..N 兜底），不是「Java 实体属性名」；列名提示的准确规则是 FROM/JOIN 后提示表名、其余子句提示列名（含 `别名.` 前缀联表提示与注释检索）
- sql-log.md 20 行括号里「启动时自动捕捉」与设置真实名称「项目启动时自动开始监听」不一致
