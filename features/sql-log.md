# SQL 日志工具窗口
<GifPlayer src="/demo/sql-log.gif" alt="控制台日志还原演示" />

自动捕获运行控制台的 `Preparing:` / `Parameters:` 日志，还原成可执行 SQL，并可精确跳转到触发这条 SQL 的源码位置。

## 触发方式

侧边栏「MyBatis SQL Log」工具窗口 → 点击「捕捉」按钮开始监听。

设置页「项目启动时自动开始监听」开启后无需手动点按钮：打开项目、运行 / 调试项目时都会自动开始捕捉。开启设置本身不会立即开始监听，等运行项目时才触发。手动点「停止捕捉」会抑制自动启动，本会话内不再自动弹回；只要开关还开着，下次运行项目时又会自动开始。

## 功能特性

### 自动捕获

监听运行控制台的日志输出，识别 `Preparing:` 和 `Parameters:` 行，自动还原成完整 SQL。同时支持 Hibernate（`Hibernate:` + `binding parameter`）与 Spring JdbcTemplate 日志格式（SQL 折成多行的语句也能跨行完整收集，字符串内的方括号不会误判截断；`NamedParameterJdbcTemplate` 单行日志的命名参数若为集合值，按元素还原——`IN (:p)` 配 `param=[a]` 还原为 `IN ('a')`，方括号不再落进 SQL 字面量），默认开启。

同时开启 Hibernate `show_sql` 与 logger 双路打印时，同一条 SQL 会自动合并为一个条目，参数归到一处，不再出现零参残留与「参数数量不匹配」误报；预览时若语句完全没有捕获到参数绑定日志，面板会提示未捕获到参数并引导开启 TRACE 级别，只有参数确实不齐才提示数量不匹配。

### 自动展开工具窗口

设置页「发现 SQL 时自动打开日志窗口」（默认开）生效时，捕获到第一条 SQL 会自动展开日志工具窗口——60 秒防抖、展开不抢编辑器焦点。几点行为说明：

- 只随 SQL 捕获发生：开关开着但从未开始捕捉（「项目启动时自动开始监听」也关着）时不会弹；点「停止捕捉」后自动展开一并失效
- 手动关掉窗口后，本次会话内不再自动展开，不会出现「关了又弹回」；设置开关重新开启、重启 IDE，或（「项目启动时自动开始监听」开启时）再次运行项目后恢复
- 升级前手动关过该开关的老用户保持关闭，不受默认值变化影响

### 混合前缀匹配

支持多种日志格式：
- `Preparing: SELECT ...`（MyBatis 默认）
- `==> Preparing: SELECT ...`（Spring Boot）
- 自定义前缀（设置页配置）

### SQL 高亮与耗时显示

- 列表中的 SQL 摘要按词法着色：关键字、表名、字符串、数字、注释分色显示，时间戳与耗时用灰色弱化，不抢 SQL 的视觉焦点
- 自动从日志中解析执行耗时，兼容 p6spy `elapsed`、MyBatis-Plus `Time:` 统计及自定义耗时前缀（设置页可配，默认 `Time:`）
- 耗时按阈值着色：小于 100ms 灰色、100ms 以上橙色、达到慢查询阈值（默认 1000ms，可配）红色
- 点击排序按钮可按耗时降序排列；存在慢查询时显示慢查询计数

### 条目序号

列表条目元信息行最前显示 `#N` 序号，表示本次会话内第 N 条捕获的 SQL，方便定位「第 N 条」：

- 每次以应用 / 测试等运行配置启动项目时从 1 重新计数（其他无关进程启动不会重置计数），手动清空列表同样归零
- 去重丢弃、暂停捕捉、关键字过滤命中的 SQL 不占号，列表不跳号
- 按耗时排序时序号保持可辨认，可看出原始捕获顺序；历史文件读回的条目不带序号

### CRUD 类型颜色标记

列表按语句类型给条目加颜色标记（SQL 日志列表与「SQL 历史」页二级列表生效）：SELECT 蓝、INSERT 绿、UPDATE 橙、DELETE 红（默认色，均可自定义），OTHER 类型不标记。

- 标记形态三选一：**左侧色条**（默认，条目左缘 3px 色条，选中态为平台高亮、色条保留）；**整行淡背景**（底色与列表背景按主题混色，亮暗主题均自适应；选中态保留类型色调并带一圈描边，耗时快 / 慢着色不会被选中高亮抹掉）；**关闭**（恢复无标记外观）
- 日志页「类型过滤」弹窗的每个复选框旁带对应类型色块图例，颜色改动即时同步（标记关闭时不显示图例）
- 配置在设置页「SQL 日志」分组的「CRUD 颜色标记」，四色与形态可改，一键恢复默认

### 跳转到源码

右键日志条目 →「跳转到源码」，行为分三级：

1. **精确跳转（推荐配置）**：SQL 日志本身不含调用位置，插件提供了可选的运行期拦截器方案——把插件自带的自包含示例 `SqlSourceInterceptor`（见插件仓库 `docs/instrumentation/SqlSourceInterceptor.kt`）复制到你的项目并注册为 MyBatis-Plus `InnerInterceptor`：

   ```java
   @Bean
   public MybatisPlusInterceptor mybatisPlusInterceptor() {
       MybatisPlusInterceptor interceptor = new MybatisPlusInterceptor();
       // 限定你自己的业务包，调用点定位更准
       interceptor.addInnerInterceptor(new SqlSourceInterceptor(Set.of("com.example.")));
       // 分页等其他拦截器按需追加
       return interceptor;
   }
   ```

   拦截器在 SQL 执行线程捕获真实调用点，向控制台打印一行 `SQLVIS-SOURCE|相对路径|行号` 标记（不影响 SQL 执行、无性能负担），插件解析后即可像 SQL 历史面板一样精确 `file:line` 跳转——直达触发这条 SQL 的 Service / Controller 行
2. **按表名搜索（默认回退）**：未配置拦截器时，自动从 SQL 中提取表名并按表名搜索对应实体 / Wrapper 所在位置，多数场景可用但可能跳不准；多模块项目、源码根不在常规位置的项目按模块 content root 逐个匹配，跳转成功率更高
3. **无表名**：如 `SELECT 1` 这类语句无可跳转目标，提示无法跳转

### 去重与过滤

| 功能 | 说明 |
|------|------|
| 去重窗口 | 相同 SQL 在窗口内重复不显示（默认 60000ms，可调；判重忽略首尾与连续空白差异，参数不同仍算不同语句） |
| 即时去重 | 勾选「移除重复的sql」后，窗口内已有的重复条目立即裁剪，并显示 `⨉N` 徽章标记丢弃数量 |
| 关键字过滤 | 移除包含指定关键字的日志行 |
| 时间戳显示 | 条目列表显示捕获时间 |

### 三种显示模式

列表工具栏提供显示模式下拉，控制条目中 SQL 的展示形态，切换即时生效：

- **单行**：每条日志固定一行，长 SQL 截断显示
- **关键字换行**（默认）：SQL 按关键字折行，行数随内容伸缩
- **格式化**：完整格式化排版，长语句逐子句展开

SQL 日志页与「SQL 历史」页共享同一设置，重启 IDE 后保留；任意模式下选中条目 Ctrl+C 复制的都是纯 SQL，不是渲染文本。

### 单击预览与双击弹窗

列表条目为两级预览（SQL 日志列表、历史 tab 二级列表、历史工具窗三处一致）：

- **单击条目**：稍候片刻弹出轻量预览——SQL 按词法高亮显示，可直接编辑；头部「复制」按钮取当前编辑后的文本，点击后图标闪变对号提示已复制，另有「关闭」按钮；弹窗锚在被点行下方不遮挡列表内容，弹出即聚焦、可直接打字修改
- **双击条目**：打开完整预览弹窗（同 Wrapper 预览弹窗，支持参数回填和格式化）。弹窗工具栏提供横排 / 竖向排列 / 关键字换行切换与「更多」菜单（导入参数、差异对比、分享等低频动作收纳其中）；竖排展示下 INSERT 每个值行尾带 `-- 列名` 配对标注（可在设置中关闭），IN 列表元素少于 5 个保持同行、达到 5 个才逐行展开；切换后的显示形态在参数回填时保持，不会被重新渲染抹掉（点刷新复位）。预览弹窗为非模态，执行 SQL 时如数据源密码过期，IDEA 的密码输入框可正常置顶输入；未配置数据源时预览静默准备，不再拉起 Database 工具窗抢占侧边栏，仅显式执行时才引导配置

列表条目的展示形态由工具栏「显示模式」控制（见上节）。字段较多的 SQL 还可开启自动折叠：设置页「字段较多时自动折叠」（默认关，阈值可配，默认 10）开启后，预览编辑器把 SELECT / INSERT 列清单、VALUES 组、UPDATE SET 等超长字段列表收起为「… N 列」占位符，点折叠标记即可还原——主预览弹窗、单击预览、历史预览、Log → SQL 结果区与原生 Database 控制台一并生效。

## SQL 历史

勾选「自动保存历史 SQL」（设置页，默认关）后，超出列表上限被淘汰的条目自动写入保存文件，历史 tab 可随时回看：

- **一级（默认视图）**：文件列表，每行显示文件名、文件大小和 SQL 条数，搜索框按文件名过滤
- **二级（文件内容）**：双击文件进入，逐条展示该文件的 SQL（同样带高亮、耗时、时间戳与源码位置）；单击 SQL 轻量预览、双击打开完整弹窗，右键可复制 SQL 或跳转到源码；搜索框按 SQL 内容 / 源文件过滤
- **返回**：顶部「← 返回」回到文件列表；切换 tab 自动刷新，正在浏览的文件仍存在时不打断浏览
- **参数识别与回填**：历史条目与实时日志走同一识别通道，双击打开弹窗同样支持参数回填；历史文件（v2 格式）随条目保存参数（以 `-- pd:` 注释行内嵌在语句旁）——旧版插件会忽略该行照常打开，新版可正常读取全部旧文件

历史文件默认保存在项目 `.idea/sql-visualizer/sql-history/` 目录（v2026.9.2 起目录名由 `mybatis-plus-sql-visualizer` 改为 `sql-visualizer`，旧目录数据不再读取），保存目录与文件名模板均可在设置页自定义。
