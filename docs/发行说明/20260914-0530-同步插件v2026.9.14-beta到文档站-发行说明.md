## 新增内容

1. **CRUD SQL 生成新功能页**（中英 features/crud-sql + 中英 sidebar 各 +1 项 + 英文首页矩阵 Other 组 +1 行）：实体类文件 / 项目视图实体节点 / Database 工具窗表节点三入口右键「生成 CRUD SQL」，候选浮层（SELECT 全表 / 按主键、INSERT、UPDATE、DELETE，打字过滤、Enter / 双击选定、ESC 关闭）选定后进既有预览窗口；INSERT / UPDATE 复用批量面板列勾选（自增主键默认不勾），`@Version` 列 SET 尾 `= version + 1` 并追加 WHERE，逻辑删除实体在实体侧额外提供「DELETE（逻辑删除）」变体（`UPDATE 表 SET 逻辑列 = 1`，delval 自定义值可面板直改），无主键 WHERE 降级 `1 = 0` 占位提示；Community 版仅实体侧入口，表节点入口需 Ultimate
2. **SQL 列表 CRUD 类型颜色标记入档**（中英 sql-log 新节、中英 configuration SQL 日志表 +1 行、roadmap 日志与历史 +1 条）：SELECT 蓝 / INSERT 绿 / UPDATE 橙 / DELETE 红默认色均可自定义，形态三选一（左侧色条默认 / 整行淡背景 / 关闭），淡背景选中态保留类型色调加描边；类型过滤弹窗复选框带色块图例；OTHER 不标记
3. **SQL 列表三种显示模式入档**（中英 sql-log 新节、roadmap 日志与历史 +1 条）：工具栏下拉切换单行 / 关键字换行（默认）/ 格式化，日志页与历史页共享同一设置重启保留，Ctrl+C 复制纯 SQL
4. **错误 / 反馈一键上报入档**（中英 configuration 更新与诊断表 +1 行、roadmap 平台与生态 +1 条）：帮助菜单「SQL Visualizer 反馈 / 需求池」、设置页「报告问题...」、IDE 内部错误对话框三入口直达官网需求池；异常堆栈附件默认不附带，IDE / 插件版本自动携带，24 小时去重
5. **SQL 预览字段列表自动折叠入档**（中英 configuration SQL 预览表 +2 行、sql-log 单击预览节尾段、roadmap 预览与诊断 +1 条）：SELECT / INSERT 列清单、VALUES 组、UPDATE SET 收起为「… N 列」占位符（默认关，阈值默认 10），主预览 / 单击预览 / 历史预览 / Log → SQL 结果区 / 原生控制台六点位生效
