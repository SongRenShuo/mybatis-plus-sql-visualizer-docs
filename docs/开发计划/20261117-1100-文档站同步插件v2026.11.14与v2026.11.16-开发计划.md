## 4. 实施清单

### T1 features/wrapper-preview.md（zh + en）

- 新增小节「**语句类型与预览目标**」（置于「动态条件勾选」之前，「功能特性」首个子节）：meta 行写「类型依据: `remove()` 消费（第 235 行）」；同一 wrapper 多处消费时工具栏出现「语句: UPDATE」下拉，列出全部档位（方法名 + 行号）按需切换，悬停列全部候选；判型取离光标最近的一条
- 小节内补判型边界三条：重新赋值即分段（锚点在哪段只收那段条件）；`list.remove(wrapper)` 等 JDK 容器同名调用不改判 DELETE；声明与消费分离（`w = new …; service.remove(w);`）照旧判 DELETE
- SET 逐列填值：`update(entity, w)` 的 SET 每列各有参数来源（`patch.order_no`），一行一列、填哪个改哪个
- INSERT 列名提示与 IDEA 原生提示互斥让位：检测到原生在位只留一枚；Community / 未装 DatabaseTools / 检测不到时照旧提示；IDEA 侧关掉后本插件不补回
- 「执行 SQL」节补两句：打开预览只显示 SQL、执行控制台第一次执行（或切换数据源）时才准备；打开 mapper 文件时后台预热一次装配（只算不建界面），首开更快

### T2 features/code-completion.md（zh + en）

- 新增小节「**列名候选与大小写**」：实体列名候选同时收录原名 / snake / UPPER_SNAKE 三形态（实体 `delFlag`、SQL 写大写蛇形时敲 `DEL_F` 能补出 `DEL_FLAG`）；插入形态跟随输入大小写（大写 SQL 提大写、小写提小写、混合按实体原形态；别名照常可搜）
- 小节内补 MBG 边界：`selectByExample(XxxExample)` 不再把 Example 条件对象当实体推假列（按 MBG 约定回查同包实体，查不到跳过）；mapper 接口与泛型都解析不到时，从语句文本 FROM / JOIN 表名反查实体兜底取列
- 性能一句：打开 mapper XML 即后台备好表 / 列上下文，跨文件片段名与配置变量清单项目级建一次按需取用，大工程连续补全不再逐文件重扫

### T3 features/xml-preview.md（zh + en）

- 「跨命名空间 include」补：片段改了立刻生效（按 namespace 查 IDE 索引，不再有短暂旧值）；片段内 `@常量@` 静态常量能求值（此前一律为空；常量声明在父类或接口上时按 `@子类@常量` 解析）
- 「Mapper 双向跳转」补一段：跳转解析走 IDE 索引（大工程毫秒级出答案、不再长期缺席）；索引未就绪时不再闪没（会话内确认过存在的语句不再消失）；接口方法删掉或 namespace 改名后图标立即摘除
- MBG 小节预取句扩为：大工程里首次打开立即出占位骨架，条件解析后台落地后自动补上真实条件

### T4 features/ibatis-preview.md（zh + en）

- 「双向箭头」补一段：XML 语句行的跳转箭头只认裸 `id` 或本文件 `namespace.id` 两种引用形态，不跨命名空间认领同名语句；调用代码改名或删除后箭头随之消失（无调用点不出）
- DAO 调用行图标一句：跳转解析走 IDE 索引，大工程不再慢半拍、中途被打断不再无故消失

### T5 guide/configuration.md（zh + en）

- 「界面与操作」表新增两行：「首次捕获 SQL 时显示一次性提示」（开）、「SQL 方言无法确定时显示一次性提示」（开），作用列写清触发时机与跳过条件
- 「数据库方言」配置项指向的方言推断折叠块补一段：打开含 SQL 的文件时后台判一次，既无数据源、配置、依赖坐标也无语法特征可依（真死路）才弹一条提示——说明按 MySQL 兜底渲染、遇 Oracle / PostgreSQL / SQL Server 会有差异，给「去设置方言」（直达设置并高亮方言行）与「本项目不再提示」两个动作；每台机器至多一条，歧义 / 冲突不弹

### T6 features/sql-log.md（zh + en）

- 引导文案订正（:23）：首次捕获成功的指路通知从「会话内一次」口径改为**每台机器一次**（持久化记忆），并写明三个跳过场景（日志窗已开着 / 本次捕获刚把它自动展开 / 开关被关掉）；与设置页两个一次性提示开关呼应

### T7 guide/offline.md（zh + en）

- 「本地安装包目录」段补保存时机：选好或填好目录立即保存（无需点应用），重启不再重填；删空目录同样被记住（等于关闭该通道）；路径不合法时不保存并在状态行说明原因
