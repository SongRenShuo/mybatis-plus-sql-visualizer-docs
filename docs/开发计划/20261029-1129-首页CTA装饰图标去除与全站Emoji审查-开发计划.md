# 首页 CTA 装饰图标去除与全站 Emoji 替换-开发计划

> 日期：2026-10-29（12:00 修订：范围从「删除图标」改为「用非 emoji 的等价内容替换」）
> 状态：计划待实施（本轮只出计划，未改代码、未部署）
> 范围：官网首页 CTA 区块 + 需求池组件的全部 emoji（必做）；功能页/指南/内部文档（明确不改）
> 关联：工具站 `jvtools-home` 的同类改造见该仓 `docs/开发计划/20261029-1200-需求池Emoji图标替换与全站Emoji审查-开发计划.md`，两仓各自实现、不共享代码。

## 一、问题与结论

用户反馈：官网首页最下方 Get Started 区块的 ✨ 图标有 AI 味，希望去掉；并明确要求 emoji 不要简单删掉，而是用其他内容替换，同时排查全站同类问题。

生产环境核实：`curl https://sql-visualizer.jvtools.cn/` 返回的首页 HTML 中确实有 `<span class="cta-badge-icon" data-v-364058a4>✨`，即该图标在线可见，不是本地残留。

审查结论分四层：

1. 营销页面（首页九个区块、吸顶导航、页脚）里，装饰性 emoji 只有 CTA 这一处，其余区块没有同类图标。
2. 同类问题集中在需求池（`/about/feedback` 及其抽屉）：4 个类型图标（✨🐛⚡❓）和 6 处零散 emoji（📌💬👍📎🔁⚠）。
3. 功能详解页与使用指南里出现的 ⚠、ℹ、⚙ 不是装饰，而是对插件自身输出前缀和 IDE 真实按钮的引用，改了会让描述与产品不符，必须保留。
4. 另有一类非 emoji 的 AI 味候选：福利卡的蓝→青渐变文字与渐变圆底。是否处理需要用户定夺，不纳入默认范围。

替换原则：每个 emoji 都换成能表达同一语义的非 emoji 载体——功能图标换内联 SVG 描边图标，纯装饰且无独立语义的（CTA 那个 ✨）由已有文字承接，不另造图形。

## 二、审查方法与范围

- 扫描对象：`git ls-files` 中全部 240 个 `.vue / .js / .ts / .md / .json / .svg / .scss / .css / .mjs` 文件（仓库共 393 个跟踪文件，其余为图片、GIF、字体等二进制资源）。
- 方法：按 Unicode emoji 区间逐行匹配，共命中 227 行；剔除 `docs/` 内部文档后，剩余 41 行属于站点可见面。
- 判定口径：按「是否真的渲染到页面」「是否承载功能语义」「是否纯装饰」三档分开，避免把产品截图说明里的符号误当成装饰图标删掉。

## 三、审查结果

### 3.1 首页 CTA 的装饰图标

| 编号 | 位置 | 形态 | 处置 |
|---|---|---|---|

## 四、实施方案

### T1 首页 CTA 的 ✨ 换成纯文字徽标（必做）

1. 删除 `CtaSection.vue` 模板第 13 行的 `<span class="cta-badge-icon">✨</span>`。
2. 删除对应样式块 `.cta-badge-icon { font-size: 0.875rem; line-height: 1; }`，并把 `.cta-badge` 的 `gap: 0.4rem` 一并去掉（只剩一个文本子节点，gap 已无作用）。
3. 胶囊徽标保留，内容变为纯文字。这里 emoji 的等价内容就是徽标文字本身：它已经表达「现在就能试」，再补一个图形属于重复表意，正是要去掉的那类装饰。若后续认为需要视觉锚点，只能用 6px 品牌色实心圆点（纯 CSS，非 emoji、非渐变），默认不加。
4. 中英文共用同一模板，改一处两边同时生效，`homeContent.js` 不需要动。

### T2 需求池类型图标换内联 SVG（必做）

1. 新建 `.vitepress/theme/components/feedback/FbIcon.vue`：`name` 属性 + 路径表，统一 `viewBox="0 0 24 24"`、`fill="none"`、`stroke="currentColor"`、`stroke-width="2"`、`stroke-linecap="round"`、`stroke-linejoin="round"`，尺寸由父级 CSS 控制，避免在 8 个文件里复制同一段 SVG。
2. 图标映射（手写路径，不引第三方图标库）：

| name | 语义 | 尺寸 | 路径来源形态 |
|---|---|---|---|
| `plus-square` | 功能需求 | 14px | 圆角方框 + 十字 |
| `bug` | Bug | 14px | 虫身 + 六足（可用简化三足版本） |
| `trending-up` | 体验优化 | 14px | 折线上扬 + 右上箭头 |
| `help-circle` | 疑问咨询 | 14px | 圆 + 问号 |
| `plus-circle` | 动态-新反馈 | 14px | 圆 + 十字 |
| `refresh` | 动态-状态变更 | 14px | 双弧箭头 |
| `pin` | 置顶 | 13px | 图钉 |
| `message` | 评论数 | 13px | 对话气泡 |
| `thumbs-up` | 点赞 | 16px | 拇指 |
| `paperclip` | 附件 | 15px | 回形针 |
| `alert` | 校验提示 | 14px | 三角感叹号 |
| `check` | 选中/成功 | 12px | 对勾 |

3. 现有颜色体系沿用：类型色仍在 `types` 数组里（`#3b82f6 / #ef4444 / #f59e0b / #8b5cf6`），图标吃 `currentColor`，不改配色。
4. 无障碍：图标与文字并排时加 `aria-hidden="true"`、`focusable="false"`；仅图标承载语义的按钮（点赞）保留原 `title`。
5. 筛选下拉（`FeedbackPool.vue:213-216`）直接去掉 emoji 前缀，只留中文/英文标签，避免下拉项里出现彩色图形。

### T3 零散 emoji 收口（必做，与 T2 同批）

按 3.2 的 B5～B11 逐个替换；每个位置保留原有 `title`、`aria-label`、动画与配色，只换图形载体。`VoteButton` 的点赞飘字动画与乐观更新逻辑不碰。

### T4 渐变复核（待定，需用户确认后才做）

若用户确认要收，按 3.4 逐项改为单色/描边方案；默认不动，避免把一次「去图标」变成整站视觉改版。

## 五、实施步骤

1. T1：改 `CtaSection.vue` 模板与样式，`npm run build`。
2. 构建产物自检：在 `dist` 的首页 chunk 里确认 `cta-badge-icon` 与 ✨ 均不存在；同时确认英文首页渲染的是同一份组件。
3. T2/T3：先落 `FbIcon.vue`，再按 3.2 表格逐文件替换，每个文件改完即 `npm run build`；最后跑一次全站 emoji 复扫，确认用户可见面只剩 3.3 白名单内的符号。
4. 视觉核对：首页 CTA 区块在亮/暗两色、桌面与 375px 窄屏下，徽标文字仍水平居中、上下间距不变；需求池四类图标在亮/暗两色下可区分。
5. 提交：按仓库惯例只 `git add` 本次改动文件并提交，不 push；部署按任务流程另行确认。

## 六、验收边界

- 首页 CTA 区块不再出现任何 emoji；徽标文字居中，胶囊宽度随文字自适应，不出现左侧多出的空白。
- 中英文首页表现一致；亮色与暗色下徽标文字对比度不下降。
- 需求池（列表、看板、详情抽屉、提交表单、动态流）：类型图标在四个类型间可区分、选中态与配色不变、深色模式下描边清晰；投票、置顶、评论数、附件、校验提示的语义与位置不变。
- 功能详解页与指南中的 ⚠ / ℹ / ⚙ 原样保留，文案不改。
- 不引入图标库依赖，不新增网络请求。

## 七、待验证前提

- 「生产首页确实带 ✨」已用 curl 实测确认，不是推断。
- 删除图标后徽标宽度与居中不变：`.cta-badge` 的 `padding: 0.375rem 1rem` 左右对称，理论上删掉图标只会缩短宽度；仍需构建后目视一次，确认没有因 `inline-flex` 残留 gap 造成偏移。
- 需求池 emoji 全部来自前端常量：已核对 `FeedbackPool.vue:272/395`、`FeedbackDetail.vue:158-161`、`FeedbackForm.vue:174-177`，`RoadmapBoard` 的 `typeIcon` 由父组件传入，均无后端字段参与；若后续发现接口另有图标字段，需先核对再改。
- 替换为 SVG 后的深色模式对比度未实测，验收时须在暗色下逐项看一遍。

## 八、用户决策（2026-10-29 已定）

1. T4 渐变：不动。福利卡的渐变文字与渐变圆底保持现状。
2. CTA 胶囊徽标：先保留纯文字版（去 ✨）；**同日复评后改为整块删除**——「立即体验」与眉题 GET STARTED、主按钮「立即免费下载」重复，且插件需先安装才能用。已删除徽标节点、`.cta-badge` 样式与 zh/en 的 `cta.badge` 文案，眉题下间距补到 1.5rem。
3. T2/T3 按计划执行，emoji 全部换内联 SVG。
