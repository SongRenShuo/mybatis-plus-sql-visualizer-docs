# 同步插件 v2026.9.10 / v2026.9.11 到文档站 — 发行说明

> 发布：2026-09-12
> 范围：文档站功能内容与插件主分支 v2026.9.10（发行 2543203）/ v2026.9.11（发行 4a62cbb）两个版本对齐（上一轮同步点 20260910-0512，v2026.9.8 / v2026.9.9）
> 红线执行：新增描述逐条对照插件 master 源码 / 语言包核实（PluginSettings.kt、PluginSettingsPanel.kt、SqlFormatter.kt、DynamicInstallSupport.kt、SqlLogParamCodec.kt、双语 bundle），未核实到源码依据的条目一律不入档

## 新增内容

1. **自更新免重启入档**（中英 configuration 更新节、roadmap 平台与生态、首页矩阵 Update Check → No-Restart Update）：「立即安装」后新版在运行中的 IDE 内热替换即时生效，不再要求重启；不支持动态安装的环境或任一环节失败自动回退重启脚本，无中间态。并收录动态安装后平台「插件未完全卸载」信息级提示的归因说明（GC 观察窗口期一次性提示，重启即清无功能影响）
2. **零占位符字面量参数恢复入档**（中英 configuration SQL 预览表 +1 行）：日志 SQL 无 `?` 占位符时把字符串字面量识别为可编辑参数（设置项默认开）；数值常量仅在比较 / IN / BETWEEN / VALUES 语境识别，`LIMIT` 与投影列常量不误认
3. **历史 SQL 参数记忆入档**（中英 sql-log SQL 历史节 +1 条、roadmap 日志与历史 +1 条）：历史文件 v2 格式随条目保存参数（`-- pd:` 注释行内嵌），旧版插件忽略该行照常打开、新版可读全部旧文件；历史条目与实时日志同一识别通道，弹窗同样参数回填
4. **竖向排列值行列名标注开关入档**（中英 configuration SQL 预览表 +1 行）：竖排展示时 INSERT 每个值行尾显示 `-- 列名` 配对注释（设置项默认开）

## 更新内容

5. **Hibernate 双路打印合并**（中英 sql-log 自动捕获节、roadmap 日志条、首页矩阵 Auto Capture 行）：`show_sql` 与 logger 双路打印同语句合并为一条，参数不分裂、不再误报数量不匹配；零参时提示引导开启 TRACE
6. **预览弹窗显示形态与「更多」菜单入档**（中英 sql-log 双击弹窗节）：横排 / 竖排 / 关键字换行切换在参数回填时保持（刷新复位）；竖排 IN 列表少于 5 个元素保持同行；导入参数 / 差异对比 / 分享折叠进「更多」菜单
7. **行号计数口径细化**（中英 sql-log 条目序号节）：仅应用 / 测试等运行配置启动重新计数，无关进程启动不重置
8. **roadmap 尾注发行收口**（中英）：改为「已随 v2026.9.8 ~ v2026.9.11 正式发行」
