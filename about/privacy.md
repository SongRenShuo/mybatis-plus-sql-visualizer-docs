# 隐私说明

本页说明 sql-visualizer.jvtools.cn 网站与 SQL Visualizer 插件各自处理哪些信息。一句话概括：网站只记匿名的访问计数，插件不收集任何数据。

## 本站收集什么

网站带一套自建的访问埋点，只记录两类事件：

- 页面访问（页面路径、时间）
- 下载按钮点击（点了哪个下载入口）

事件经本站自己的 `/api/v1/track` 接口上报，存在自建库里。埋点内容不含任何代码内容——事实上它也拿不到：插件的一切分析都发生在你本机的 IDE 进程里，网站侧无从感知。

## 你主动提交什么

- **需求池反馈**：你在反馈页提交的类型与描述，以及随附的 IDE 与插件版本号，仅用于需求跟进与回复。
- **悬赏邮箱**：参与需求悬赏时填写的邮箱，仅用于奖励发放与对应需求的沟通。

这些信息只由站长用于上述目的，不对外提供。

## 涉及的第三方

- **Cloudflare Pages**：本站托管在 Cloudflare Pages 上，访问过程适用 Cloudflare 自身的隐私政策（含其标准日志处理）。
- **JetBrains Marketplace**：插件的下载、安装与账号体系在 JetBrains 侧完成，适用 JetBrains 的隐私政策，与本站无关。

## 不做什么

- 无广告
- 无第三方统计或跟踪脚本（埋点是自建的，数据不流向第三方）
- 插件不上传你的代码：预览、还原与反向转换都是本地静态分析，SQL 与代码内容不出本机

有疑问或想删掉已提交的反馈信息，欢迎到[需求池](/about/feedback)提出。
