## 一、复核方法与判据

| 项 | 做法 |

| 机械指标 | Pillow 逐张读尺寸 / 帧数 / `duration×n_frames` / 体积；poster 与 GIF 的 mtime 对账 |
| 画面内容 | 每张抽 5 帧（首 / 15% / 40% / 65% / 尾）目视；结论不明或怀疑短事件被采样漏掉时**回原 GIF 全帧重抽** |

### 4.1 跳行弹窗的根因（本轮最重要的发现）

`Go to Line:Column` 弹窗在 6 张里命中。逐条查录制脚本后定案：

- 跳行由 `lib/nav.py` 的 `goto()` / `goto_col()` / `goto_token()` 与 `gifkit.goto_line()` 实现，两者都是
  **Ctrl+G → 清空 → 输入行号 → Enter**；从 Ctrl+G 到 Enter 之间约 **1.5~2.0 秒**，弹窗在这段时间里
  一直可见——15fps 下就是 **20~30 帧**。
- 上一轮（20261024 计划）的修法是「`goto_col` 末尾无条件按 Esc」，但 **Esc 在 Enter 之后**，
  弹窗早已入镜，该修法对「弹窗入镜」这个现象**无效**（实测 `lib/nav.py:116-129` 的 `goto_col`
  末尾也没有 Esc）。
- 真正的修法是**把跳行移出录制窗口**（在 `Recorder.start()` 之前完成），或改用不弹窗的定位方式
  （gutter 点击 / `Ctrl+F` 搜索 / MCP `open_file_in_editor` 按路径精确打开）。
