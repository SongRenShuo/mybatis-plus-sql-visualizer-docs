## 三、红线核对（每条新增表述的源码出处）

1. **O-76 全角括号容错**：`SqlStatementSplitter.kt` dev diff 实证——`c == '(' || c == '（'`、`c == ')' || c == '）'` 同栈计数；修复两形态：`（…)` 混对误切、`(…）` 混对 parenDepth 泄漏吞并后续语句；字符串态先行保证字符串内全角字符不受影响。测试 5 例 + 反向验证 91 例 3 红→0。
2. **R22 T-01 预览参数记忆扩展**：`ParamHistoryCache.kt` dev diff 实证——`computeKey` 无表名分支由「返回 null 不缓存」改为 `sql:` + `normalizeSqlWhitespace` + `sqlFingerprint` 指纹持久化；有表名键 `tableName:fingerprint` 逐字节兼容；消费点召回/保存自动对纯文本预览生效。功能本体（T-ParamBulk 历史召回）已存在，站内此前零表述，本轮在 roadmap 一行写全本体+扩展。
3. **0926 批次 roadmap 补登记**：跳转落点双修复（2eed8f9 判定缓存深度比选 / c25d780 JAR 业务帧判据）+ JAR 业务帧反向名单设置项（7a6fc81 端到端）+ 前缀校验一键修复（5f11629）——全部已合 master 且已在 configuration/sql-log 页详述，本轮仅补 roadmap「已完成」登记行，无新能力表述。
4. 官网 jvtools-home（22ca369，工作树干净）：插件区为 4 张通用能力卡（Wrapper 预览 / 日志还原 / SQL→Java / MCP 十工具），不携带版本细节表述，本轮两笔增量不触碰卡片口径——**零改动**。
