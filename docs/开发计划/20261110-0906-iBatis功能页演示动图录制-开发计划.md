## 一、为什么要录

新页承诺的两个核心能力都是**动态行为**，纯文本说服力不足：

- 「参数可交互」——条件行勾选、值可填、SQL 随填值变化，这是 v2026.11.10-beta.1 才补全的交互面，用户看文字想象不出「按行勾选 14 种 `<isXxx>`」是什么手感；
- 「双向跳转」——语句行与 Java DAO 调用行的箭头互跳，是静态截图表现不了的。

素材已就绪：demo 仓 `ibatis2-demo` 模块是**纯静态语料**（README 自述「没有 Spring、没有数据源、不连库」），无需准备 `mp_demo` / `mpj_demo` 数据源，也无需方言切换——比大多数录制少一大块前置。

## 二、录什么（2 张，1 主 1 辅）

| # | 图 | 内容 | 投放位 |
|---|---|---|---|
| 1 | `ibatis-preview`（hero，导出宽 1280） | 打开 `sqlmap/User.xml` → 光标压 `selectByCondition` → gutter 预览 → 条件行勾选 / 取消 → 填值 → SQL 实时变化 | 页首 H1 之后（en 镜像同位置） |
| 2 | `ibatis-nav` | 语句行箭头跳到 `UserDaoImpl` 调用行，再点调用行箭头跳回 XML 语句 | 页内「双向跳转」节 |

选 `selectByCondition`（`User.xml:129`，`<dynamic>` 四条件共存）做 hero 的理由：一个语句同时展示条件勾选、`$username$` 直替、`#id#` 占位三种形态，信息密度最高。`selectByIterate`（159 行，`<iterate>` + `#ids[]#`）作为备选强化镜头——若 hero 时长富余（≤15s）可加一段「填值列表展开 `ids[0..2]`」。

## 四、场景分镜设计

### 4.1 GIF 1（hero）

1. **就位（`Recorder.start()` 之前）**：MCP `open_file` 按路径打开 `User.xml`（坑 53，别走 `Ctrl+Shift+N`）→ 等索引完成（坑 44）→ `Ctrl+Home` + `post_wheel` 滚到 129 行一带（**不用 `goto*`**，坑 61）→ 光标压语句 → 断言 gutter 图标存在（像素检测）；

3. **交互（撑时长的主变化，坑 52）**：条件行「取消勾选 `isNotNull id`」→ WHERE 少一段 → 「勾回」→ 「`username` 条件填值 `tom`」（**不带引号**，引号由插件决定——沿用既有约定）→ SQL 实时变化 → 收尾停在预览面板左栏空白区（坑 27 落点）；
4. **归一**：条件面板折叠态跨预览保留（skill 标定节），take 前把面板归一到已知态。

### 4.2 GIF 2（双向跳转）

1. **就位**：`User.xml` 停在 `selectById` 语句行（`:88` 一带）；
2. **正向**：点语句行 gutter 箭头 → 跳到 `UserDaoImpl.java` 的调用行（断言编辑器落到 Java 文件）；

## 六、验收口径

1. **三件套同名**（`ibatis-preview` / `ibatis-nav` 各 `.gif` + `.mp4` + `.webp`），`deliver.py` 裁框后零损失校验（PSNR inf 或 ≥78dB）；
2. **体积**：MP4 单件 ≤600KB；
3. **首帧 / 关键动作帧 / 尾帧**各写一句「看到了什么功能动作」，写不出即不通过；
4. **alt 名词与画面对应**：alt 里每个名词（gutter 图标、条件行、箭头、文件名）都要能在画面里找到；
5. **动画确认交用户真实浏览器**（IAB 能播 GIF，但最终动画判据只能真实可见渲染）；
6. 对着**已提交的那份文件**逐帧看（对着现场/中间产物验收会得出相反结论——20261026 教训）。

## 九、风险

1. **同名文件**：demo 仓 `User.xml` 只此一份（无 MyBatis 同名文件），风险低；仍按惯例走 MCP 按路径开文件；
2. **录制独占键鼠**：录制期间不能并行跑构建；发现被抢前台立刻停手说明；
3. **预览面板初始态**：折叠区展开态跨预览保留，take 前必须归一（skill 标定节，暗色主题阈值取 22）；
4. **hero 时长**：交互段（勾选 + 填值）是时长主变化，别只靠鼠标游走（坑 52，纯凝视会被静段裁到 3 秒级）；
5. **跳转落点断言**：`selectById` 在 `User.xml` 与 `UserDaoImpl` 两侧都要断言落点行内容，避免「跳了但跳错」；
6. **页面 alt 一致性**：GIF 1 的 alt 要覆盖「条件勾选 + 填值」两个动作；若实际只拍到其一，alt 按实拍写、不承诺未拍到的（沿用批 4 文案回滚约定）。
