# Vue 生产构建与开发构建的区别

- 记录时间：2026-09-03 13:00
- 项目：sql-visualizer-admin（Cloudflare Workers + D1 方案）

## 问题描述

使用 `vue.global.prod.js`（生产构建）时，Vue 模板语法（`{{ }}`、`v-if`、`v-model`）未被编译，页面显示原始模板代码。

切换到 `vue.global.js`（开发构建）后正常工作。

## 根本原因

Vue 3 提供两种构建版本：

| 构建 | 文件名 | 包含模板编译器 | 体积 | 适用场景 |
|------|--------|--------------|------|---------|
| 生产构建 | `vue.global.prod.js` | ❌ 不包含 | ~167KB | 使用预编译的渲染函数 |
| 开发构建 | `vue.global.js` | ✅ 包含 | ~594KB | 运行时编译模板 |

**生产构建移除了模板编译器**以减小体积，这意味着它无法编译 HTML 中的内联模板。

### 受影响的用法

以下用法**必须使用开发构建**或在构建时预编译：

1. **内联模板（Inline Template）**：直接在 HTML 中写的 Vue 模板
   ```html
   <div id="app">
     <h1>{{ message }}</h1>  <!-- 需要模板编译器 -->
   </div>
   ```

2. **运行时编译**：通过 `template` 选项传入字符串模板
   ```javascript
   Vue.createApp({
     template: '<div>{{ message }}</div>'  // 需要模板编译器
   });
   ```

### 不受影响的用法

以下用法可以使用生产构建：

1. **单文件组件（SFC）**：`.vue` 文件通过构建工具预编译
2. **渲染函数（Render Function）**：使用 `h()` 函数
3. **JSX**：通过 Babel 预编译

## 解决方案

### 方案1：使用开发构建（推荐用于简单SPA）

```html
<script src="https://unpkg.com/vue@3/dist/vue.global.js"></script>
```

优点：开箱即用，无需构建步骤
缺点：体积较大（~594KB），有控制台警告

### 方案2：使用构建工具预编译

使用 Vite、Webpack 等构建工具，将模板预编译为渲染函数。

```bash
npm create vue@latest
npm run build
```

### 方案3：使用渲染函数

```javascript
Vue.createApp({
  render() {
    return Vue.h('div', this.message);
  }
});
```

## 本项目选择

本项目是简单的 SPA 页面，使用**开发构建**（`vue.global.js`），原因：
- 页面逻辑简单，不需要复杂的构建流程
- 直接部署到 Cloudflare Pages，无构建步骤
- 体积差异（~400KB）对用户体验影响可忽略

## 经验总结

1. **不要在生产环境使用 `vue.global.prod.js` 处理内联模板**，除非你明确知道需要模板编译器
2. **对于简单的 HTML+Vue 页面**，使用 `vue.global.js`（开发构建）是最简单的方案
3. **对于复杂项目**，应使用构建工具（Vite/Webpack）预编译模板，然后使用生产构建
4. **CDN 引用时注意文件名**：
   - `vue.global.js` = 开发构建（包含编译器）
   - `vue.global.prod.js` = 生产构建（不包含编译器）
