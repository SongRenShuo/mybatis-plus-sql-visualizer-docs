## 一、为什么这一轮必须做

文档站 52 张动图里，**9 张停在 2026-09-12~09-20 的旧构图**（预览面板按钮行没有「复制 SQL 并关闭」、日志工具栏是 `AllIcons` 旧图标、SQL→Java 页签还挂着 Beta），另有 3 张虽较新（10-12~10-16）却缺新按钮行或新图标形态；而插件在这五周里新增了二十余项用户可见能力、并做了三轮 UI 改版（工具栏图标语义统一、预览面板按钮行重构、SQL 日志列表与历史列表重做）。直接后果是：

1. **画面与真实界面不符**：`annotation-preview.gif` / `batch-operation.gif` / `code-completion.gif` / `jpa-preview.gif` / `xml-preview.gif` / `sql-to-java.gif` / `crud-sql.gif` 等旧片里，预览面板按钮行仍是「压缩 / 格式化 / 关键字换行 / 竖向排列 / 执行计划 / 刷新 / 更多」的旧排布，底部是「执行 SQL / 复制 SQL / 取消」三按钮；当前版本已加入「复制 SQL 并关闭」蓝色主行动（`d65fb457`→`ab674aaa`→`47dc43e8`→`e213009e`，均已在 tag 内）。
2. **功能图完全缺失**：本版新增的 FieldFill 安全模拟、DML 影响面预演、一键诊断报告、EXPLAIN 跨会话计划历史与跨次对比、导出回放脚本、复制为 AI 上下文（含表列名出口）、展示与导出脱敏、方言闸门阻断态两出口、回滚快照表格/文本双态与 CSV 编辑器、执行视图「返回预览」、历史列表直达末条、SQL 日志交流群入口——**一个都没有配图，部分连正文都没有**。
3. **正文有 6 处与新版本直接冲突**：最严重的是增强捕获的授权口径（本站仍写「24 小时冷却 + 重新授权 + 三态确认弹窗」，而 `T-EnhancedCaptureDefaultOn` 早已移除这套机制）。本轮已就地修正，见 §八。

## 四、动图录制执行规格

- **启动命令**（插件仓 `master`）：
  ```bash
  python record/bootstrap-robot-server.py
  ./gradlew runIde -PgifRecord=true -PgifRobotServer=true \
    --args=F:/code/Java/Gitee/SongRenShuo/mybatis-plus-sql-visualizer-demo
  ```
- **硬前置**：沙盒标题栏无 `Start Free Trial`、无许可对话框、Ultimate Database 可用。本轮 R01/R03~R10 的旧片正是带横幅拍的，**必须确认订阅生效再开录**。

- **录制纪律**：插件功能问题一律停录回修，不在现场改码（用户 2026-09-19 定调）；每条成片必须核对 `decoded 帧数 == Recorder.frames`。

## 七、验收与收口

1. **素材层**：每张 GIF 抽帧核对三处（动作节点 / 定格 / poster）；帧数对账；首尾同态；`.png` 与 GIF 首帧或关键定格一致。
2. **页面层**：`npm run build` 退出码 0；`.vitepress/dist/demo/` 与 `public/demo/` 逐文件摘要一致；73 处引用（新增后重扫）零缺失。
3. **浏览器层**：`npm run preview` + puppeteer 抽查新增页面 GIF 挂载与 poster 结构；**重建 dist 后必须重启 preview 服务器**（sirv 预扫文件表，陈旧映射返回 404）。
4. **动画是否在播**：只能用户目视或真实浏览器前台确认——canvas 采样对 GIF 只画首帧（2026-09-15 实证）。
5. **部署门禁**：用户逐图验收通过后才执行 `npm run deploy`；`update/update.json` 与本轮无关，不动。
