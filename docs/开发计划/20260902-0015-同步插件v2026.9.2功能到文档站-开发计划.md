## 2. 任务拆分

### Phase 1 品牌更名（全站）

- `​.vitepress/config.mts`：`title` / 两处 locale `title` + `description` 改为 SQL Visualizer，描述补一句「原 MyBatis-Plus SQL Visualizer，仍全面支持 MyBatis-Plus / MPJ / JPA / Hibernate」；域名、sitemap、Marketplace 代理不变
- `index.md` + `.vitepress/theme/CoolHome.vue`（如首页硬编码了旧名）：标题与文案同步，保留一句更名说明
- `README.md`、`guide/*.md`、`features/*.md` 中「MyBatis-Plus SQL Visualizer」字样批量替换为「SQL Visualizer」，首次出现处保留「（原 MyBatis-Plus SQL Visualizer）」
- `en/` 目录英文文案同步（SQL Visualizer）
- 设置路径文案：`Settings > Tools > MyBatis-Plus SQL Visualizer` → 新显示名

### Phase 2 功能页更新

**`features/sql-log.md`（改动最大）**：

- 新章节「跳转到源码」：
  - 精确跳转原理一句话 + 应用侧接入方法：把插件自带示例拦截器 `docs/instrumentation/SqlSourceInterceptor.kt` 注册为 MyBatis-Plus `InnerInterceptor`（附最小代码块），插件在控制台识别 `SQLVIS-SOURCE|相对路径|行号` 标记行
  - 说明行为分级：有标记 → 精确 file:line；无标记 → 自动按表名搜索实体（原行为），零配置也可用
- 新章节「耗时与慢查询」：p6spy / MP TimeCount / 自定义前缀三种耗时来源；阈值着色（<100ms 灰 / ≥100ms 橙 / ≥慢查询阈值红）；按耗时排序按钮；慢查询计数
- 「去重与过滤」表格更新：勾选「移除重复的sql」后窗口内既有重复条目立即裁剪并显示 ⨉N 徽章（不再只对新条目生效）
- 新章节「SQL 历史」：历史 tab 两级导航（文件列表：文件名 / 大小 / 条数 → 双击进文件 → 双击 SQL 预览）；右键复制 SQL / 跳转源码；搜索框分别按文件名 / SQL 内容过滤；历史文件存于 `.idea/sql-visualizer/sql-history/`
- 数据目录变更提示框：旧目录 `.idea/mybatis-plus-sql-visualizer` 数据不再读取，升级后历史从新目录起算

**`features/xml-preview.md`**：

- 页面标题与首段扩展为「XML 动态 SQL 预览」+ 新章节「HQL / JPQL 预览」：实体类 / DAO 方法行 gutter 图标触发；支持多行拼接与链式赋值的 HQL 字符串识别；`SELECT u` 实体别名自动展开为列清单（无 SELECT 子句自动补列、JOIN 副表降级 `alias.*`），解决 MySQL `Unknown column 'u'` 报错
- `guide/getting-started.md` 功能入口清单如有列表，同步补 HQL 入口一句

**`features/wrapper-preview.md` / `features/sql-to-java.md`**：核对「双击预览弹窗」描述，补一句弹窗为非模态、执行时数据源密码框可正常置顶（对应 #10）

## 4. 验证

1. `npm run docs:dev` 本地起站，逐页过一遍中英两个语言版本
2. 事实核对：配置项名称 / 默认值与插件 `PluginSettings` 实际字段一致（三重核实原则——发行说明 + 插件源码 + 设置面板），重点核对 `autoCheckUpdate` 默认值、`slowQueryThresholdMs` 默认值、数据目录常量 `SqlLogAutoSaver.DATA_DIR_NAME`
3. `npm run docs:build` 构建通过（`ignoreDeadLinks: true` 已开，但仍尽量不引死链）

## 5. 发布

构建产物经 wrangler 部署 Cloudflare Pages（Gitee 不被 CF Pages 支持）：

```bash
npm run docs:build
npx wrangler pages deploy .vitepress/dist --project-name=<既有项目名>
```

部署命令以记忆文档「deployment-target」记录为准，发布前先核对项目名。

## 6. 风险与备注

- 更名范围以「显示名」为限：文档站域名 `mybatis-plus-sql-visualizer.jvtools.cn`、Gitee 仓库地址、Marketplace 页地址均不变，文案中不要引导用户去找新地址
- HQL / JPQL 预览的触发入口（哪些文件类型有 gutter）写文档前需在插件源码确认 `HqlGutterLineMarkerProvider` / `CustomDaoHqlGutterLineMarkerProvider` 的注册范围，避免写错入口
- 慢查询阈值、自动保存等配置项是否存在及默认值，落笔前以插件设置面板为准，不照抄发行说明
- 历史数据不迁移是明确决策（不考虑向前兼容），文档措辞直接说明，不承诺兼容
