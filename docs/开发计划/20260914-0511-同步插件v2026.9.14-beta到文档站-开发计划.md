# 开发计划：同步插件 v2026.9.14-beta 系列新功能到文档站

> 日期：2026-09-14 05:11
> 仓库：mybatis-plus-sql-visualizer-docs（文档站 / 官网，Cloudflare Pages）
> 上游：mybatis-plus-sql-visualizer master（v2026.9.14-beta.1 / beta.2，tag 2026.9.14-beta.1、v2026.9.14-beta.2 发行记录见插件 CHANGELOG）

## 一、背景

文档站上次同步到插件 v2026.9.10 / 9.11（commit 48699ee，尾注收口 v2026.9.8 ~ 9.11）。此后插件 master 又合入了两个 Gitee 内测版：

- **v2026.9.14-beta.1**（2026-09-12）：T-CrudSql 实体类 / 数据库表右键生成 CRUD SQL、T-AutoFold SQL 预览字段列表自动折叠、T-SelToggle 全选 / 全不选按钮合一，以及 MPJ 括号条件反向转换退化修复等；
- **v2026.9.14-beta.2**（2026-09-13）：dev 分支与 t-crudcolor 分支整体回合 master——T-CrudColor SQL 列表 CRUD 类型颜色标记、T-ErrReport 错误 / 反馈一键上报、T-ListMode 三种显示模式、T-Perf 性能系列等。

其中 ORM 识别域扩展（xbatis / Easy-Query / MDS / Querydsl / Specification / QBE / JdbcTemplate / 自研 DAO）、gutter 左键预览 / 右键最近执行反查、真实 EXPLAIN、自动监听被动模式等 dev 侧功能，已在 0906 / 0908 / 0910 三轮同步入档（见 commit 5dae1d0、1077c80、4fc3547），本次不再重复。真正的增量为六项。

## 二、红线与口径

1. **只写源码里存在的东西**。六项功能全部在插件 master 源码逐项核实过（类文件、plugin.xml 注册、i18n 文案、PluginSettings 默认值、验收文档入口速查），出处见下表。
2. **发行渠道必须写准**。这批功能目前只随 v2026.9.14-beta.1/2 在 Gitee 抢先体验通道（内测）发行，JetBrains Marketplace 正式版仍停在 2026.9.11。roadmap 尾注按渠道分口：Marketplace 可更新到的范围不变，新增条目注明「随 v2026.9.14-beta 内测先行，正式版 2026.9.14 发行后并入」。功能页正文按插件能力描述（与 0906 轮 dev 功能先入档的先例一致），不虚构版本号。
3. **演示 GIF 不在本次范围**。8 个功能页现有 GIF 全部沿用；新增的 CRUD SQL 生成页暂不配 GIF，后续随下一轮录制计划补拍（页面结构预留首屏位置）。

### 功能核实清单（源码证据）

| 功能 | 源码证据 | 关键口径 |
| --- | --- | --- |
| 右键生成 CRUD SQL | `actions/GenerateCrudSqlFromEntityAction.kt`、`actions/GenerateCrudSqlFromDbTableAction.kt`、`generator/CrudSqlGenerator.kt`、plugin.xml `EditorPopupMenu`/`ProjectViewPopupMenu` 注册、database-optional.xml 表节点入口 | 双入口三落点（实体类文件 / 项目视图实体节点 / Database 工具窗表节点）；候选浮层 JBPopup（打字过滤、Enter / 双击选定、ESC 关闭）；INSERT / UPDATE 复用 BatchModel 列勾选（自增主键默认不勾）；`@Version` 列 SET 尾 `= version + 1` 并进 WHERE；逻辑删除实体出 `DELETE（逻辑删除）` 变体（仅实体侧）；无主键降级 `WHERE 1 = 0` 占位；Community 版仅实体侧入口 |
| 字段列表自动折叠 | `ui/highlight/SqlAutoFoldPlanner.kt`、`SqlAutoFolding.kt`；bundle `settings.autoFold.enabled`（默认关）、`settings.autoFold.threshold`（默认 10）、`preview.fold.placeholder=… {0} 列` | SELECT / INSERT 列清单、VALUES 组、UPDATE SET 元素数 ≥ 阈值且跨多行才折叠；覆盖主预览 / 单击预览 / Log→SQL 结果区 / SQL 输入区 / 原生控制台 |
| CRUD 类型颜色标记 | `log/SqlListTypeColor.kt`（默认色 `#4A86E8`/`#4CAF50`/`#E67E22`/`#D32F2F`，STYLE_BAR/BACKGROUND/OFF）、`SqlListSelectionOutline.kt`；PluginSettings `crudColor*` 5 个设置项 | 日志页与历史页二级列表生效；形态三选一（左侧色条默认 / 整行淡背景 / 关闭）；淡背景选中态为类型色调加深 + 2px 描边；类型过滤弹窗复选框带色块图例（关闭形态不显示）；OTHER 不标记 |
| 三种显示模式 | bundle `log.list.displayMode.*`（单行 / 关键字换行 / 格式化）、`SqlListDisplayMode` 枚举默认 `KEYWORD_WRAP` | 日志页 / 历史页工具栏下拉即时切换，两列表共享同一设置，重启保留；Ctrl+C 复制纯 SQL |
| 错误 / 反馈一键上报 | `feedback/FeedbackAction.kt`（plugin.xml HelpMenu 注册）、`IdeErrorReportSubmitter.kt`、`FeedbackReporting.kt`、`FeedbackApi.kt`（API_BASE = 官网 /api/v1）；bundle `error.report.*` | 三入口：帮助菜单「SQL Visualizer 反馈 / 需求池」、设置页「报告问题...」、IDE 内部错误对话框一键报告；对话框含类型 / 分类 / 描述，异常堆栈附件默认不附带；IDE / 插件版本自动携带；24 小时去重 |
| 全选 / 全不选按钮合一 | T-SelToggle（afef857） | 预览「动态条件」「批量列」与日志类型过滤弹窗三处双按钮合一为随勾选态切文案的单按钮。文档站从未写过这两个按钮，无需改文——只在发行说明记一笔 |

## 四、验证与部署

1. `npm run build` 全站构建通过（llms.txt / pagefind 索引随构建产出）；
2. `npm run preview` 本地起服，curl 核对新增页与改动页 200、中英 sidebar 出现新条目；
3. 浏览器打开新功能页与 roadmap 目检：无死链、样式与既有页一致、渠道口径表述准确；
4. `npm run deploy`（wrangler pages deploy --branch main）上线后 curl 生产域复核；
5. 测试通过即 commit（只 add 本次文件，不 push）。
