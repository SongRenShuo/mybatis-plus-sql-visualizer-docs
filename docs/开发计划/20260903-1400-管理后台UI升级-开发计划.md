## 二、技术选型

### 2.1 组件库：Element Plus（首选）

**理由**：
1. **管理后台匹配度最高**：表格（排序/筛选/树形/虚拟滚动）、表单（复杂校验）、布局容器、Menu 等一应俱全
2. **社区与维护**：27.7k star、19.8k fork、1-4 周发版、美团/CRMEB 等大规模使用
3. **设计成熟**：遵循「一致性、反馈、效率、可控性」四大设计原则，无 AI 味
4. **暗色模式**：内置 CSS 变量 + `ConfigProvider`
5. **文档双语**：中文文档完善

**备选**：如果偏好 TypeScript 优先和更「手工感」的现代风格，可选 **Naive UI**。

### 2.2 构建方案

当前管理后台是单 HTML + Vue CDN。组件库需要构建工具才能正常使用，**推荐迁移到 Vite + Vue SFC 工程**：

```
sql-visualizer-admin/admin/          # 独立前端工程
├── package.json
├── vite.config.ts
├── index.html
├── src/
│   ├── main.ts                      # Element Plus 注册
│   ├── App.vue                      # 根组件
│   ├── router/
│   ├── layouts/
│   │   └── AdminLayout.vue          # 侧边栏 + 顶栏 + 内容区
│   ├── views/
│   │   ├── Login.vue
│   │   ├── Dashboard.vue
│   │   ├── Posts.vue                # 反馈管理
│   │   ├── Notifications.vue        # 通知日志
│   │   ├── Stats.vue                # 数据统计
│   │   └── Settings.vue             # 系统设置
│   ├── api/
│   │   └── index.ts                 # API 封装
│   ├── stores/                      # Pinia 状态
│   ├── styles/
│   │   └── tokens.css               # 设计 token
│   └── components/
├── .env                             # VITE_API_BASE 环境变量
└── package-lock.json
```

**CDN 备选方案**：Element Plus 也支持 CDN 引入，但相比 Vite 工程：
- ❌ 组件按需加载不可控
- ❌ 无法使用 SFC 和类型检查
- ❌ 热更新开发体验差

如果坚持单 HTML，可用 Element Plus CDN（`element-plus` + `@element-plus/icons-vue`），但**强烈推荐 Vite 工程**以获得专业开发体验。

## 三、设计规范

### 3.1 色彩 Token（结合 Ant/Arco 取值）

```css
/* styles/tokens.css */
:root {
  /* 主色 */
  --color-primary: #1677ff;
  --color-primary-hover: #4096ff;
  --color-primary-active: #0958d9;

  /* 功能色 */
  --color-success: #52c41a;
  --color-warning: #faad14;
  --color-error: #ff4d4f;

  /* 中性色 */
  --color-text-primary: #1d2129;
  --color-text-secondary: #4e5969;
  --color-text-tertiary: #86909c;
  --color-border: #e5e6eb;
  --color-border-strong: #d9d9d9;
  --color-bg-page: #f5f5f5;
  --color-bg-surface: #ffffff;
}

/* 暗色模式（Element Plus ConfigProvider dark） */
.dark {
  --color-primary: #4096ff;
  --color-text-primary: #ffffffd9;
  --color-text-secondary: #ffffffa6;
  --color-border: #424242;
  --color-bg-page: #000000;
  --color-bg-surface: #1d2129;
}
```

### 3.2 排版

```css
:root {
  /* 字体栈（去 AI 味，用系统+主流） */
  --font-family: -apple-system, BlinkMacSystemFont, 'Segoe UI', Roboto, 'Helvetica Neue', Arial, sans-serif;
  --font-size-xs: 12px;   /* 表格辅助文字 */
  --font-size-sm: 13px;   /* 表格内容 */
  --font-size-base: 14px; /* 正文/表单 */
  --font-size-lg: 16px;   /* 卡片标题 */
  --font-size-xl: 20px;   /* 页面标题 */
  --font-size-2xl: 24px;  /* 大标题 */
}
```

### 3.3 布局

| 区域 | 尺寸 | 说明 |
|------|------|------|
| 侧边栏 | 232px（折叠 64px） | 深色或浅色，Menu 组件 |
| 顶栏 | 56-64px | 面包屑 + 操作区 + 用户头像 |
| 内容区 | padding 24px | 卡片 + 表格 + 统计 |
| 表格行高 | 40-48px | 密集 32px |

### 3.4 文字/表格/卡片设计要点

- **避免过多卡片**（参考 Vercel）：统计只做最关键几个，用留白和排版表达层级
- **表格**：仅水平边框、无斑马纹/可选、hover 行 `#F7F8FA`、表头透明 + 13px 中等字重
- **状态**：用 Element Plus `el-tag` 表达反馈状态（Submitted/Review/Planned/Done...）
- **操作按钮**：主操作 `primary`、危险删除 `danger`、次要 `default`
- **间距**：8px 基准网格（4/8/16/24/32）

## 四、页面重构清单

### T1 项目迁移：Vite + Vue SFC + Element Plus

| 任务 | 说明 |
|------|------|
| 创建 `admin/` 前端工程 | Vite + Vue 3 + TypeScript + Pinia + Router + Element Plus |
| main.ts 注册 | `app.use(ElementPlus)` + 图标 + 暗色 |
| `.env` 配置 | `VITE_API_BASE=https://api.sql-visualizer.jvtools.cn/api/v1` |

### T2 布局组件 AdminLayout

| 任务 | 说明 |
|------|------|
| 侧边栏 | `el-menu`，路由驱动（反馈/统计/设置/通知） |
| 顶栏 | 面包屑 + 标题 + 暗色切换 + 用户菜单（退出） |
| 内容路由 | `<router-view>` |

### T3 登录页 Login

- 居中卡片，品牌 logo + 标题
- `el-form` 表单校验（用户名/密码必填）
- 登录后存 token + 跳转 Dashboard

### T4 反馈管理 Posts

- `el-table`：编号/标题/类型/状态/投票/评论/创建时间/操作
- 状态用 `el-tag`（颜色映射：Submitted 灰 / Review 橙 / Planned 蓝 / Progress 紫 / Done 绿 / Declined 红 / Duplicate 灰）
- 状态变更用 `el-select` 内联编辑
- 搜索 `el-input` + 筛选 `el-select` + `el-pagination`

### T5 数据统计 Stats

- `el-statistic` 统计卡：总反馈/总投票/评估中/已完成
- 状态分布：`el-table` 或 `v-charts`（分类占比）

### T6 通知日志 Notifications

- `el-table` 通知记录 + 状态 `el-tag` + 失败重发按钮

### T7 系统设置 Settings

- `el-form` 配置项编辑 + 保存
- 切换开关用 `el-switch`

### T8 暗色模式

- Element Plus `ConfigProvider` + `dark` class
- 顶栏暗色切换按钮，持久化到 localStorage

### T9 部署

- `npm run build` → `wrangler pages deploy admin/dist --project-name sql-visualizer-admin`

## 五、风格自检清单（避免 AI 味）

- [ ] **不要过度使用渐变/投影**，用 1px 细边框 + 留白表达层级
- [ ] **不要堆满卡片**，每屏 3-4 个关键统计即可
- [ ] **不要用 emoji 作图标**，用 Element Plus 图标库或语义色
- [ ] **不要花哨动画**，仅 0.2s 过渡 + hover 高亮
- [ ] **文案克制**，按钮/标签用简短中文，不用机械模板句
- [ ] **间距统一**，用 8px 基准网格
- [ ] **色彩克制**，主色一种 + 功能色做状态，不用彩虹色
- [ ] **排版清晰**，正文 13-14px，标题用字号区分而非加粗滥用

## 六、风险与缓解

| 风险 | 概率 | 影响 | 缓解 |
|------|------|------|------|
| 迁移工作量 | 高 | 需重构现有单 HTML | 组件逻辑简单，逐步迁移 |
| Element Plus 体积 | 中 | 首屏加载 | 按需自动导入 + `unplugin-vue-components` |
| Vite 构建学习曲线 | 中 | 开发速度 | 模板化，快速上手 |
| 现有 API 兼容 | 低 | 字段映射 | 沿用现有 API，前端做字段适配 |
