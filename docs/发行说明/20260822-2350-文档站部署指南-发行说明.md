# 文档站部署指南

> 适用项目：基于 VitePress 构建，部署到 Cloudflare Pages
> 最后更新：2026-08-22

---

## 1. 前置条件

| 工具 | 用途 | 安装 |
|------|------|------|
| Node.js | 构建 VitePress | ≥ 18 |
| wrangler CLI | 部署到 Cloudflare Pages | `npm install -g wrangler` |
| Cloudflare 账号 | 托管服务 | 免费计划即可 |

---

## 2. 首次部署

### 2.1 安装依赖

```bash
npm install
```

### 2.2 构建

```bash
npm run build
```

构建产物输出到 `.vitepress/dist`。

### 2.3 登录 Cloudflare（一次性）

```bash
wrangler login
```

会打开浏览器完成 OAuth 授权。

### 2.4 部署

```bash
wrangler pages deploy .vitepress/dist --project-name <项目名> --branch main --commit-dirty=true
```

参数说明：
- `--project-name`：Cloudflare Pages 项目名称（首次部署自动创建）
- `--branch main`：指定生产分支
- `--commit-dirty=true`：允许有未提交的更改时部署

部署成功后会输出类似：
```
✨ Deployment complete! Take a peek over at https://xxxxxx.<项目名>.pages.dev
```

## 3. 日常更新

每次修改文档内容后：

```bash
npm run build && wrangler pages deploy .vitepress/dist --project-name <项目名> --branch main --commit-dirty=true
```

## 4. 自定义域名配置

### 4.1 添加域名到 Pages 项目

通过 Cloudflare API：

```bash
curl -X POST "https://api.cloudflare.com/client/v4/accounts/<账户ID>/pages/projects/<项目名>/domains" \
  -H "Authorization: Bearer <API_TOKEN>" \
  -H "Content-Type: application/json" \
  -d '{"name": "子域名.你的域名.cn"}'
```

### 4.2 添加 DNS CNAME 记录

在 Cloudflare Dashboard 中：
1. 进入域名 → **DNS** → **记录**
2. 点击 **添加记录**
3. 填写：
   - 类型：**CNAME**
   - 名称：**子域名前缀**（如 `docs`）
   - 目标：**`<项目名>.pages.dev`**
   - 代理状态：**已代理**
   - TTL：**自动**
4. 保存

DNS 生效后（几分钟到几小时）即可通过自定义域名访问。

## 5. 项目配置要点

### 5.1 主题设置

`.vitepress/config.mts` 中：

```typescript
export default defineConfig({
  // 'light' 亮色 / 'dark' 暗色
  appearance: 'light',
})
```

### 5.2 忽略死链接

开发文档中可能包含 localhost 链接，构建时会报错。在配置中忽略：

```typescript
export default defineConfig({
  ignoreDeadLinks: true,
})
```

### 5.3 站点域名

更新 sitemap 和 JSON-LD 中的域名：

```typescript
head: [
  ['script', { type: 'application/ld+json' }, JSON.stringify({
    'url': 'https://你的域名',
  })]
],
sitemap: {
  hostname: 'https://你的域名'
}
```

## 7. 常见问题

**Q: 构建时报死链接错误？**
A: 确保 `.vitepress/config.mts` 中设置了 `ignoreDeadLinks: true`

**Q: wrangler 未认证？**
A: 运行 `wrangler login`，浏览器完成授权后重试

**Q: 自定义域名无法访问？**
A: 检查 CNAME 记录是否正确添加，DNS 传播需要时间。可通过 `dig 子域名 CNAME` 验证

**Q: 部署后页面不更新？**
A: 浏览器可能有缓存，尝试强制刷新（Ctrl+Shift+R）
