# 配置详解

所有配置位于 `Settings > Tools > MyBatis-Plus SQL Visualizer`。

设置变更无需重启 IDE：重新触发预览即按新配置生效。

## SQL 预览

| 配置项 | 默认值 | 作用 |
|--------|--------|------|
| 数据库方言 | MySQL | 分页 / upsert 子句按方言渲染 |
| 替换 ? 占位符 | 开 | 关闭后变量也渲染为 `?` |
| 格式化输出 | 开 | 多行缩进（关 = 单行） |
| 逻辑删除注入 | 开 | `@TableLogic` 时自动追加 `AND deleted = 值` |
| 逻辑删除值 | 0 | 逻辑删除条件的值 |

## 表名映射

| 配置项 | 默认值 | 作用 |
|--------|--------|------|
| 表前缀 / 表后缀 | 空 | 推断表名统一加前缀 / 后缀 |
| 移除表名前缀 / 后缀 | 空 | 推断表名去除指定前缀 / 后缀 |
| 忽略字段名 | 空 | 指定字段不进 SELECT 展开与补全 |
| 表名推断策略 | SNAKE | SNAKE 驼峰转下划线 / CAMEL 保留驼峰 |

## 代码生成（SQL → Java）

| 配置项 | 默认值 | 作用 |
|--------|--------|------|
| SQL→Java 默认 Wrapper 形态 | 自动 | AUTO / QUERY / LAMBDA / WRAPPERS / MPJ |
| 自动推断失败时允许手动选择实体类 | 开 | 关闭后纯自动推断 |

## SQL 日志

| 配置项 | 默认值 | 作用 |
|--------|--------|------|
| SQL / 参数前缀 | `Preparing:` / `Parameters:` | 控制台日志识别前缀 |
| 自动捕捉 | 关 | IDE 启动后自动开始监听 |
| 发现 SQL 自动打开窗口 | 关 | 捕获到 SQL 时自动打开日志工具窗口 |
| 时间戳显示 | 开 | 条目列表显示捕获时间 |
| 去重窗口 | 60000 ms | 相同 SQL 在窗口内重复不显示 |
| 移除包含关键字 | 空 | 过滤包含指定关键字的日志行 |

## 界面与操作

| 配置项 | 默认值 | 作用 |
|--------|--------|------|
| 代码左侧显示预览 SQL 图标 | 开 | Wrapper 锚点行 gutter 图标入口 |
| 界面语言 | 简体中文 | 插件 UI 语言（English / 跟随系统可选） |
| 快捷键 | `Alt+Shift+Q` / `Alt+Shift+J` | 分别对应 Wrapper 转 SQL 与 SQL→Java |

## 更新与诊断

| 配置项 | 默认值 | 作用 |
|--------|--------|------|
| 启动时自动检查更新 | 开 | 启动静默检查，发现新版弹通知 |
| 检查更新 / 下载并安装 | - | 手动检查更新、一键下载安装 |
| 插件缓存 | - | 显示缓存占用大小，可一键清除 |
| 内部构建号 | - | 每次构建唯一，反馈问题时一键复制 |
