## 二、交付范围

### 2.1 奖励档位

| 等级 | 区间 | 有效建议 | 部分有效建议 |
|------|------|----------|--------------|
| 严重 | ¥6.88–9.88 | ¥8.38 | ¥4.20 |
| 高 | ¥4.88–6.88 | ¥5.88 | ¥2.90 |
| 中 | ¥2.88–4.88 | ¥3.88 | ¥1.90 |
| 低 | ¥0.88–2.88 | ¥1.88 | ¥0.90 |

单笔硬上限 `maxReward=988` 分；默认月度预算 `monthlyBudget=2000` 分（¥20）。

### 2.2 预算口径

- 审核通过（状态 3 待发放）时写 `budget_month=当前月（UTC+8）`，立即占用当月预算；
- 已发放（状态 4）保留原 `budget_month`，不重复占新月份；
- 重新打开/撤回/撤销通过清空 `budget_month`，释放预算；
- 无效/重复/金额 0 不占预算；
- 已用 = `status IN (3,4) AND budget_month=当前月` 的金额合计；
- 状态阈值：`reached`（≥100%）、`near_limit`（≥80% 且 <100%）、`normal`。

### 2.3 公开与管理行为

| 面 | 行为 |
|----|------|
| 公开 policy | 返回 `budgetStatus`；**不返回** `monthlyBudget/monthUsed/monthRemaining`；`Cache-Control: no-store` |
| 公开提交 | 达到上限仍 200 正常受理；响应仅 `submissionNo` |
| 公开页面 | 页首/表单提示「即将达到上限」或「已达到上限，仍会正常受理」；**不禁用提交**；不显示任何预算金额 |
| 管理 policy | 完整策略含 `monthlyBudget`；超管可改 |
| 管理 stats | `monthBudget/monthUsed/monthRemaining/budgetStatus`；保留 `monthPaidAmount` 为实际发放口径 |
| 管理审核 | 正数金额超本月剩余 → 409「本月悬赏预算不足」；金额 0 仍可审核（状态 5 + 说明） |
| 发放 | 不重复扣当月预算；历史空 `budget_month` 按审核月/当前月补写 |
| 释放 | reopen/withdraw/revoke-approval 清空 `budget_month` |
