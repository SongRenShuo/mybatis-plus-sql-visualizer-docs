|---|---|---|

## 4. 实施清单

### T1 新建 iBatis 功能页（zh + en + 侧栏）

`features/ibatis-preview.md`、`en/features/ibatis-preview.md`，侧栏 zh/en 各加一项（排在「XML / HQL 动态 SQL 预览」后）。结构按站点功能页模板：

- 定位（iBatis 2.x sqlMap 与 MyBatis 同待遇：预览/着色/补全/跳转）
- 触发方式（`<sqlMap>` 语句行 gutter 图标；识别三选二判据；不会把 MyBatis 3 `<mapper>` 误判）
- 预览（占位四态 `#p#`/`#p:jdbcType#`/`#p:jdbcType:nullValue#`/`#p,jdbcType=?`、`$p$` 直替、`##`/`$$` 转义；条件标签 14 个 `<isXxx>`、`<dynamic>` prepend、`<iterate>`、`<sql>`/`<include>`、`<selectKey>`；保真口径——iBatis 2.3.4.726 黄金对照 20 形态逐字节一致，`prepend` 粘连原样复现不美化）
- 参数可交互（条件行勾选、值可填、iterate 填值列表、数值比较修正、parameterMap 按位对齐取真实属性名）
- 编辑辅助（注入着色、折叠、`#`/`$` 补全、属性值刻意不注入的原因；两份 DTD 随包离线）
- 双向跳转（XML 内部 id 引用；Java DAO statementId 8 方法；双向箭头；**让位门与 MyBatis 解耦**——竞品在位箭头照常显示）
- SQL 列表（IBATIS 独立来源角标；控制台 `{pstm-N}` 日志还原）
- 降级可见（横幅分档、如实标注哪个标签什么原因）
- 已知边界（跨文件 id 清单、XML→Java 反查、selectKey 隐式 id、Kotlin DAO、参数行逗号切分、批处理不支持）
- 反馈池引导尾链（`?category=xml` 复用或新增——查 feedback 页 category 枚举后定）
