用户点名要求：官网首页体现「更新无需重启 IDEA」「内网环境离线可用」特色。

### 3.2 features/sql-log.md（中英）

1. 新增「两种捕获通道」节（触发方式之后）：增强捕获（默认通道）八点口径——注入确认一次、无需应用开启 SQL 日志、真实参数（默认不脱敏可打码）、毫秒级耗时、影响行数、报错信息、目标库角标（9 方言 + openGauss/GBASE）、数据留本机 + 失败自动回落控制台捕获 + 停止监听联动停采 + JDK 21+ 动态挂载告警说明（JEP 451，取自插件确认弹窗文案）
2. 「SQL 高亮与耗时显示」：耗时点补增强条目结构化毫秒值；排序点由「点击排序按钮按耗时降序」改写为排序方式选择器（常驻按钮 + 单选菜单五种 + 缺失恒沉底 + 时间排序跟随时间来源）
3. 「跳转到源码」：按通道拆分——增强捕获条目取自真实调用栈直达代码行、自研框架统一入口自动上溯跳过框架帧（设置页「源码捕获帧过滤前缀」可配，实时与历史面板共用同一解析）；控制台通道保留拦截器方案原文
4. 「单击预览与双击弹窗」：单击预览补「零占位符字面量 SQL 与 IN 列表同样识别出可编辑参数行」；双击弹窗 IN 竖排规则改「含逗号即 ≥2 元素一律逐行（单元素仍同行，子查询 IN 与 LIMIT 分页参数照旧不展开）」
5. 「三种显示模式」后陈旧句修正：「工具栏『显示模式』」→设置页「列表显示」（第六轮漏网）
6. 「SQL 历史」：自动保存描述改「条目全量落盘（不受列表最大条数限制）」；补「历史文件保留上限（默认 30 个，0 = 全量保留）自动清理最旧」
