## 二、分镜（scene_t9_crudsql.py，约 10 秒）

单主线走**实体侧编辑器右键**入口（Community 也可用的主路径，与文档页「触发方式」第一落点一致）。Database 表节点入口不做第二分镜——官方风格一支视频只演示一个功能点，表节点入口在文档页已有文字承载。

1. 打开 `User.java`，光标平滑移至类名行，右键呼出编辑器上下文菜单，停 0.5 秒（菜单内「生成 CRUD SQL」可见）
2. 点击「生成 CRUD SQL」→ 候选浮层弹出（SELECT 全表 / SELECT 按主键 / INSERT / UPDATE / DELETE / DELETE（逻辑删除）六项双行渲染），停 1 秒
3. 键入过滤字符收窄候选 → Enter 选定 INSERT，停 1 秒
4. 预览窗口出现 INSERT SQL 与批量列勾选面板（自增主键 `id` 默认不勾），停 2 秒
5. 取消勾选一列 → SQL 对应列实时收缩，停 1 秒
6. 收尾构图与首帧一致，循环不跳

poster 取分镜 4 帧（INSERT 与列勾选面板同屏，即「关键内容帧」）。

节奏与操作纪律（沿用总计划 §2.4 + 录制指南 §四）：录制前手动戳一遍每个动作确认真实生效；动静反差、关键结果停 1~2 秒；单段直出不拼接；IME 英文态；PixPin 热键冲突规避（开 Settings 走工具栏齿轮菜单）。

## 五、风险与备注

- **右键菜单项位置**：action 注册在 EditorPopupMenu 末位（anchor=last），上下文菜单过长时需确认「生成 CRUD SQL」在可视范围内；若被 IDE 分组折叠或溢出，改用 Project 视图实体节点右键入口（同一 action，分镜第 1 步平移，其余不变）
- **候选浮层为 JBPopup 轻量浮层**：定位跟随光标，编辑器滚动会漂移——脚本标定坐标前先把视图滚动到位再固定；键入过滤的响应速度以沙盒实测为准，过滤字符现场标定（「in」命中 INSERT 是否唯一待实测，不合适就换词或省略过滤直接方向键 + Enter）
- **逻辑删除变体取舍**：User 实体 `@TableLogic` 使浮层多出「DELETE（逻辑删除）」项——属真实能力，默认按全量六项录；若嫌浮层过高构图局促，换无逻辑删除注解的实体（Order / Role）变五项，二选一以画面观感定，须在实施记录里注明用了哪个
- GifPlayer hydration 补位（T12）已双保险，新页接入即受益，无前端改造量
- **一份录制两处投放**：文档站 GIF 与插件 README demo-09 为同一成片的两份拷贝（README 无 poster 机制，仅拷 GIF）；若后续成片因站点侧原因重转制，两份须同步替换，防口径漂移。4~6MB 单文件入插件仓库与既有 8 张同量级，Gitee 仓库体积无增量风险
- 录制完现场还原：杀 demo 应用与沙盒进程、注销并行任务；中间产物不进仓库（record/perf 已 gitignore）
- 部署可与下次站点更新合批；本计划单独 deploy 亦可，按当日批次定

- **结果**：`/demo/crud-sql.gif`（0.9MB，1280w，15fps，成片 11.1s，循环接缝 diff 0.00）+ 同名 `.png` poster（分镜 4/5 关键内容帧：INSERT 预览 + password 取消勾选后 SQL 收缩定格）；中英两页首屏接入 GifPlayer；插件仓库 demo-09 + scene_t9 脚本入库（commit 0fbc8a8，不 push）；站点验收 6/6 过（见 T4）。
- **逻辑删除变体取舍**：按风险预案默认项执行——全量六项候选实录（含「DELETE（逻辑删除）」），构图无局促，未换实体。
- **沙盒环境**：MPSV-GifFresh 录制沙盒（-PgifRecord=true，262/JCEF/toolchain24 随开关整体切换）因上次录制后 config 被清理，主题/缩放（Islands Dark + 120%）按基线重设一次并持久化；并行期以「条件块后置覆盖」与 t-internal-api-audit 的无条件 TEMP 行共存（仅 -PgifRecord=true 时改写回 MPSV-GifFresh），未动对方行。
- **管线新坑（沉淀）**：
  1. **PixPin 全局热键与低层钩子**是本轮最大干扰源——Ctrl+Shift+F12/Alt+1 等被劫持，且其「自定义截图」对话框对合成点击免疫（僵尸弹窗）；taskkill PixPin 后全部恢复正常。常驻截图工具建议录制期临时退出（Snipaste 提权进程杀不掉，幸而未捣乱）。
  2. **合成点击对未聚焦子窗口的「点击聚焦」吞没**：JBPopup 菜单项/对话框按钮/通知气泡的第一次合成点击常被吞（只拿到焦点不触发），可靠姿势 = 同窗口先来一次牺牲点击（激活）再点目标，或键盘（方向键/助记键/Enter，数字与方向键不经过 IME 组合态）。
  3. **右键菜单溢出窗口**：Generate CRUD SQL 在 EditorPopupMenu 末位，caret 在视口低位时菜单底项会超出窗口下缘——prep 里 goto+Ctrl+Down 把类名行推到 y≈339，菜单全高（~640px）回到窗口内。
  4. **预览窗落位动画**：JBPopup→预览窗打开后有 ~1-2s 的位置动画，勾选框坐标在动画期不稳定——脚本「双次扫描一致才点击」，扫描带只勾勾选框列（x 130-172）并跳过 id 行。
  5. **窗口 DWM 阴影带透光**：窗口 rect 底部 ~9px 透明边框会透出 z 序下方窗口的内容（当时是用户日常 IDE 的亮色工具窗条）——tkinter 纯黑垫底窗插在沙盒窗口 z 序正下方遮蔽（black_underlay.py 已入库复用）。
  6. **headless Chrome 截图不推进 GIF 动画帧**：像素帧差法在 headless 恒 0，动画判据改为「资产多帧（ffprobe 167 帧）+ GifPlayer 叠层就绪态（--ready / opacity 1）」，站点验收 6/6 即按此口径。
- **环境还原**：build.gradle.kts 临时条件块已还原；并行任务注销见注销记录；沙盒 IDE 进程现场杀掉（runIde 随之退出）；demo 仓库 git 全程零改动（两轮误触的内存态编辑均未落盘，文件与 HEAD 一致）。
