# 同步插件 dev 分支功能到文档站 — 开发计划

> 创建：2026-09-06
> 用途：插件项目 dev 分支已合入六条分支（master / perf红线治理 / M39 JPA深化 / M44 其他ORM / M37竞品融合 / jdbc-template），功能尚未发行新版本号。本计划把其中用户可感知的能力同步到文档站与官网，含 v2026.9.4（已发行）中文档站尚未覆盖的部分。
> 信息来源：插件 dev 分支 `docs/架构设计/M37M38竞品融合新增功能-说明文档.md`、`JPA-Hibernate官方API覆盖矩阵.md`、`其他ORM官方API覆盖矩阵.md`、`CHANGELOG.md`（v2026.9.4）、M54 性能红线治理计划、dev 合并交付记录（e0212d4，全量 3509 测试绿、verifyPlugin 三目标 Compatible）。

---

## 0. 红线

- **禁止在文档站和官网中写插件中不存在的功能**：所有新增描述均以 dev 分支源码为唯一权威，写入前逐条核实（本次调研已在源码确认：EXPLAIN / 生成测试按钮在 `SqlPreviewPanel.kt:404-510`；自动开窗默认值 `PluginSettings.kt:171`；五 ORM 转换器与 `WrapperLocator` 注册；JPA CRUD 转换器家族）。
- dev 能力尚未发行：功能页按能力正常描述（代码已合入、测试全绿），版本承诺只在 roadmap 用「已合入 dev，随下个发行版提供」一句话交代，不虚构版本号。
- 保持既有样式风格：表格驱动、无 emoji 标题、克制措辞、中英双语同步。

## 2. 任务拆分

### Phase 1 中文版功能页

1. **新建 `features/jpa-preview.md`**（JPA / Hibernate SQL 预览）：触发面表（派生方法、@Query JPQL、Criteria 链、HQL 调用、自定义 DAO HQL、@NamedQuery、.hbm.xml、Repository CRUD 方法）；CRUD 写路径表（save/findById/delete 家族/flush 语义/getReferenceById 标注）；派生查询要点（六前缀、Top/First/Distinct、IgnoreCase、In）；分页排序与 Page/Slice；Specification / QBE；JPQL/HQL 深化（JOIN、子查询、UPDATE/DELETE、@Modifying）；SELECT 实体别名展开（自 xml-preview 迁移）；JOIN 图原生渲染简述。文末互链 wrapper-preview / sql-log
2. **`features/wrapper-preview.md`**：触发方式表 gutter 行更新（左键直接预览、右键菜单两项）；「支持的 Wrapper 类型」补 JdbcTemplate / 自研 DAO 字符串 SQL / xbatis / Easy-Query / MyBatis Dynamic SQL / Querydsl；新增「EXPLAIN 真实执行计划」（含方言表与数据源前置）、「生成测试资产」（两形态与边界）、「最近执行记录」（指回 sql-log）三节；修第 32 行错字
3. **`features/xml-preview.md`**：HQL/JPQL 节收敛为入口简介 + 指向 jpa-preview；补 @NamedQuery 一行
4. **`features/sql-log.md`**：自动捕获节后加「自动展开工具窗」小节（默认开、防抖、不抢焦点、手动关闭本会话抑制）；跳转源码节补多模块容错一句
5. **`features/annotation-preview.md` / `batch-operation.md` / `code-completion.md`**：核对后仅在必要时微调（预计不动）

### Phase 2 中文版指南与关于

6. **`guide/configuration.md`**：「发现 SQL 自动打开日志窗口」默认值改开 + 手动关闭抑制说明；「界面与操作」补 JOIN 图原生渲染开关
