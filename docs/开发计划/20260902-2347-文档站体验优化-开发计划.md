- 立项时间：2026-09-02 23:47（2026-09-03 修订：暗色模式定为「可切换、默认亮色」；移除 Marketplace 下载量/评分实时联动；Hero 版本号改为实时获取、纯文字样式）
- 实施状态：T1~T8、T11 已于 2026-09-03 实施，详见 `docs/发行说明/20260903-0026-文档站体验优化-发行说明.md`；T9/T10/T12/T13 待排期
- 站点：https://sql-visualizer.jvtools.cn（Cloudflare Pages + VitePress）
- 目标：对齐主流开发者工具官网的体验水准，提升「访问 → 理解 → 安装」转化率与 SEO 触达

## 一、现状分析

### 已具备的基础（不需要动）

- 首页完全复刻 Cool-Request 风格，结构完整：Hero / SocialProof / FeaturesGrid / DocsShowcase / Testimonials / Pricing(福利) / CTA
- 中英双语、本地搜索、sitemap、JSON-LD（WebSite）、更新日志走 CF Function 代理 Marketplace API
- 功能详解 7 篇 + 使用指南 3 篇，内容质量过关
- public/video/ 已有 5 个真实演示视频（wrapper-preview / xml-preview / sql-log / sql-to-java / docs-showcase）

### 核心短板（本次要解决的）

| # | 问题 | 现状证据 | 影响 |
|---|------|---------|------|
| 1 | 功能页演示素材是 SVG 占位图 | features/*.md 全部 `<GifPlayer src="/demo/xxx.svg">`，而真视频躺在 public/video/ 没接上 | 用户在功能页看到的不是真实效果，说服力打折 |
| 2 | GifPlayer 只支持 img | GifPlayer.vue 模板内只有 `<img>` 标签 | 有视频也放不进去 |
| 3 | OG 图是 SVG | public/og-image.svg，head 里 summary_large_image | 微信 / X / Facebook 等爬虫不渲染 SVG，分享出去无图 |
| 4 | 暗色模式被关闭 | config.mts `appearance: 'light'` 强制亮色，home 组件未做暗色适配 | 主流文档站（Vue/Vite/TanStack）标配，IDE 用户尤其偏好暗色 |
| 5 | 首页 CTA 无安装深链 | Hero/CTA 只有文字按钮，未直导 Marketplace 安装页；socialLinks 为空 | 用户要点两层才能到 Marketplace |
| 6 | 无 hreflang | config 只有 og:locale:alternate，VitePress 不自动生成 | 中英文页面互抢排名，Google 官方推荐 hreflang 声明 |
| 7 | 无 llms.txt | - | AI 搜索时代新流量入口，VitePress 有现成插件 |
| 8 | 结构化数据单薄 | 只有 WebSite schema，无 SoftwareApplication | 搜索结果缺少分类/平台富摘要 |
| 9 | EN 区细节缺失 | 英文版搜索弹窗未翻译；about/changelog 等页 EN parity 未经校验 | 国际用户体验割裂 |
| 10 | 缺少决策辅助内容 | 无竞品对比、无快捷键速查、无版本兼容矩阵 | 「为什么选它」「我的 IDEA 版本支不支持」这类问题要靠用户自己翻 |

## 三、任务清单

优先级说明：P0 = 直接影响转化与传播，先做；P1 = 体验与 SEO 补强；P2 = 锦上添花，可按空余时间排。

### P0

#### T1 功能页接入真实演示视频

- 改造 `GifPlayer.vue`：props 增加 `video` / `poster`，模板渲染 `<video muted loop autoplay playsinline preload="metadata">`，保留 img 分支作为降级；点击暂停逻辑复用
- features 各页把 `/demo/*.svg` 替换为 `/video/*.mp4` + poster 图（视频首帧截图，可用 ffmpeg 抽帧）
- 补录缺失素材：annotation-preview、batch-operation、code-completion 三个视频（真机录屏）
- 验收：功能页全部展示真实录屏，弱网下有 poster 不白屏，移动端不自动播放出声

#### T2 首页 CTA 强化

- Hero 与 CTA 区主按钮改为「在 Marketplace 中安装」，直达 `https://plugins.jetbrains.com/plugin/33633-sql-visualizer`（IDE 运行时该页自动出现 Install to IDE 一键安装）；副按钮「下载离线包」指向 Gitee Releases
- Hero 副标题下方加一行元信息文字：`最新版本 v2026.9.x · 支持 IDEA 2024.3+ · Apache-2.0`。样式与现有 UI 正文字体保持一致（普通文本 + 间隔符，不做徽章/胶囊底色，参考 Vue 官网 hero 副标题下方的纯文字版式）
- 版本号实时获取：复用现有 `/api/changelog` 代理（Marketplace updates API 的第一条即最新版本），封装一个轻量 composable 取版本号注入该行文字；请求失败或超时静默降级为构建时的静态兜底版本号，不阻塞渲染
- NavHeader 补 Gitee / Marketplace 图标外链（NavBarGitee.vue 已有基础）
- 验收：首页两步内可达安装动作；Hero 版本行字体与周围文字无样式割裂，Marketplace API 挂掉时显示兜底版本号且无控制台报错

#### T3 OG 图换 PNG

- 制作 1200×630 PNG 版 og-image（基于现有 SVG 导出，含插件名 + 一句话卖点 + SQL 预览截图）
- config.mts head 中 og:image / twitter:image 指向 PNG，补 og:image:width/height 与 og:url
- 验收：微信 / X 分享链接出现卡片图；用 opengraph.xyz 或 metatags.io 校验

### P1

#### T4 暗色模式：支持切换，默认亮色

- config.mts `appearance: 'light'` 改为 `'switch'`——开启亮暗切换按钮，默认亮色（注：`true` 会跟随系统暗色偏好，与「默认必须亮色」的需求不符，不用）
- 逐个审计 home/ 下 11 个组件的硬编码颜色，抽 CSS 变量（`--home-bg` / `--home-text` 等）到 style.css，`.dark` 下覆盖
- ThemedImage.vue 已存在，logo / 截图类资源按需提供暗色版本
- 工作量最大的一项，可拆两批：先文档区内页（VitePress 原生支持，成本低），后自定义首页
- 验收：切换按钮出现在导航栏；默认进入为亮色；切到暗色后全站无「白底白字 / 黑底黑字」，截图类素材两套主题下均清晰

#### T5 hreflang 与结构化数据

- config.mts 增加 `transformHead`，按路由为 `/en/**` 与根路径页面互写 `<link rel="alternate" hreflang>`，含 `x-default` 指向中文版；sitemap 已开，两处配合
- JSON-LD 增加 SoftwareApplication 节点：applicationCategory=DeveloperApplication、operatingSystem=Windows/macOS/Linux、offers(price 0)
- 验收：Google Rich Results Test 通过；任一英文页 head 含互指 hreflang

## 五、风险与注意事项

- 暗色模式涉及 2000+ 行自定义首页组件，改前先跑一次完整构建留档，分组件提交；默认亮色用 `appearance: 'switch'` 而非 `true`，避免用户系统暗色偏好把默认值带偏
- Marketplace updates API 无 SLA，Hero 版本号属于增强信息，必须有静态兜底值且不能阻塞首屏渲染；下载量/评分等统计类数据按需求不做
- `jetbrains://` 深链依赖本地 IDE 注册协议处理器，官网侧不做深链直跳，统一导流到 marketplace 插件页由官方按钮接管，规避兼容性问题
- 录屏素材注意脱敏：不含真实业务表名、内网地址、公司信息
- 竞品对比页措辞保持中立客观，引用能力事实而非评价性语言
- Cloudflare Functions 改动后先在 `wrangler pages dev` 本地验证，再部署
