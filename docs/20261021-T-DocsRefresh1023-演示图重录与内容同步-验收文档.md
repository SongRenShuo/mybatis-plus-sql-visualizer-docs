## 三、待补录（环境阻塞）

以下 5 张需要 IDE 数据源处于「活控制台」状态才能演示，本轮沙盒未能稳定达成：

| # | 资产 | 阻塞现象 | 处置 |
|---|---|---|---|
| N02 | `dml-impact.gif` | 执行 SQL 报 `[1064]`——预览绑定到 `mp_demo@localhost`，该库 URL 未带 `ANSI_QUOTES`，双引号表名非法 | 需让预览绑到 `mpj_demo`（URL 带 `ANSI_QUOTES`） |
| N03 | `explain-history-compare.gif` | 同上（EXPLAIN 走同一执行链） | 同上 |
| N08 | `dialect-gate.gif` | 需构造「方言与数据源不匹配」的阻断态——要先把项目方言改成非 MySQL 再执行，属环境改动 | 需在专用会话里改方言后录，录完还原 |
| N11 | `rollback-snapshot-dual.gif` | 快照查询走只读旁路，同样需可用数据源 | 同 N02 |
| N12 | `display-mask.gif` | 需设置页勾选「展示与导出脱敏」并回到列表对比 | 设置页操作可行，但需先在列表里造出含 password 的条目 |

**已定位的根因**（供下一轮直接处理）：

1. 沙盒 `mpj_demo@localhost` / `mp_demo@localhost` 的密码未持久化，首次连接弹「Access denied (using password: NO)」，手工补 `root` 后 `mpj_demo` 连接成功（`1 of 14`）。
2. 预览的「活控制台」绑定优先取当前有控制台的库——`mp_demo` 有活控制台，于是绑了它；而 `mp_demo` 的 JDBC URL 没有 `sessionVariables=sql_mode=ANSI_QUOTES`，双引号表名（MPJ 渲染 `"user"`）在该库非法。
3. 数据源下拉是 JBPopup，**合成点击不可靠**（与录制指南第 13 条同源）——需悬停后点击，或改用键盘。

**这 5 处正文已写好，图引用已暂时移除**（避免死链）；素材补录后把 `<GifPlayer>` 行加回即可，无需改正文。
