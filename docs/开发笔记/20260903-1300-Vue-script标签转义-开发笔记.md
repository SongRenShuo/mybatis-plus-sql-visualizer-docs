# Vue 开发中 script 标签转义问题

- 记录时间：2026-09-03 13:00
- 项目：sql-visualizer-admin（Cloudflare Workers + D1 方案）

## 问题描述

在管理后台 SPA 开发中，Vue 模板语法（`{{ }}`、`v-if`、`v-model`）未被编译，直接以原始文本形式显示在页面上。同时，登录页面和主页面内容同时显示。

浏览器控制台报错：
```
Invalid or unexpected token
```

## 根本原因

在 HTML 的 `<script>` 标签内部，JavaScript 字符串中包含 `</script>` 子串时，**浏览器 HTML 解析器**会将其解释为 script 标签的结束符，导致后续 JavaScript 代码被截断。

### 问题代码示例

```html
<script>
var app = Vue.createApp({
  data: function() {
    return {
      // 这里的 </script> 会被浏览器解析为标签结束符！
      loginForm: { username: '', password: '<REDACTED> };
    }
  }
});
app.mount('#app');
</script>
```

当浏览器解析到 `</script>` 时，它会认为 script 标签已经结束，导致后面的 `};` 和 `app.mount('#app');` 被当作 HTML 文本处理，JavaScript 执行失败。

## 解决方案

### 方法1：转义斜杠（推荐）

将 `</script>` 中的 `/` 转义为 `\/`：

```javascript
loginForm: { username: '', password: '<REDACTED> };
```

### 方法2：拆分字符串

```javascript
loginForm: { username: '', password: '<' + '/script>' };
```

### 方法3：避免在 script 标签内使用

将敏感字符串定义为外部变量，或通过其他方式传递。

## 经验总结

1. **HTML 解析器优先于 JavaScript 引擎**：浏览器先解析 HTML，再执行 JavaScript。HTML 解析器看到 `</script>` 就会结束 script 标签，无论它出现在 JavaScript 字符串的哪个位置。

2. **所有 `</script>` 都需要转义**：不仅是在字符串中，任何出现在 `<script>` 块内的 `</script>` 都需要转义，包括：
   - 字符串字面量
   - 模板字符串
   - 正则表达式
   - 注释中的示例代码

3. **构建工具注意事项**：使用 Python、Node.js 等工具生成包含 JavaScript 的 HTML 文件时，确保 `</script>` 被正确转义。Python 的字符串转义（`\/`）和 JSON 序列化可能不会自动处理这种情况。

## 验证方法

```bash
# 检查 HTML 文件中的 inline script 是否有未转义的 </script>
grep -n "</script>" your-file.html
```

正确的结果应该只有外部脚本引用（如 `<script src="..."></script>`），inline script 内部不应有未转义的 `</script>`。
