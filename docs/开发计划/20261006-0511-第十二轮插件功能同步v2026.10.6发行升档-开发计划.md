## 五、口径要点

1. sql-log.md L27（新）：增强捕获的注入确认前置到任何运行之前——开启增强捕获或打开项目（出厂未确认态）时即弹一次，授权持久化先于任何 Run；同意后首轮运行即完整捕获（含启动期 SQL），不用等重启项目。核心能力：（既有列表不动）
2. details 补 4 条目（措辞见 §三 出处，逐条对齐 bundle/README 原文语义，不拔高）：
   - **确认时机**：开启增强捕获（设置页或引导链）或打开项目（出厂已开启、尚未授权的形态）时即弹注入确认，先于任何 Run；毫秒级连发只弹一个框。
   - **在跑进程补扫**：监听启动时对已在运行的应用进程自动补扫——未确认先弹确认、已确认直接挂载。
   - **能力边界如实提示**：注入失败回落 attach 热挂载成功时，提示「挂载前已创建的连接不在捕获范围，重新运行项目后完整生效」（每轮至多一次）。
   - **注入范围收窄**：`-javaagent` 只进真实应用运行任务；Gradle / Maven 的测试与 IDE 任务（`test`、`runIde` 等）fork 出的 JVM 一律不注入。
3. configuration.md L63（新）：开启或打开项目时弹注入确认（先于任何运行），同意后首轮运行即带 agent 完整采集——其余语义保留原文（无需应用开启 SQL 日志 / 真实参数耗时位置 / 失败回落 / 停止监听联动停采），补「已在运行的应用进程由补扫接管」。
4. wrapper EXPLAIN 表补行验证列：OceanBase＝「官方文档级验证（真机留账）」、openGauss＝「真机通过」；MySQL/MariaDB 行渲染形态改 `EXPLAIN <sql>`（原生表格行）。
