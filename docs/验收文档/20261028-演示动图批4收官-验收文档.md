## 五、试录不合格回退记录（无静默降级）

以下 7 张在本轮系列中试录过但最终回退到前版，原因逐条登记（详见前序验收文档 §8.2 / §10.2 / §11.3）：

| 图 | 回退原因 |
|---|---|
| `sql-log`（首版） | IDE 内 demo 未启动，控制台未挂载 → 后在 §9 轮打通 IDE 内启动后重录入库 |
| `replay-script-export`（首版） | 保存框关闭后 Chrome 抢前台，整段白屏 → 后在 §10 轮用 `AttachThreadInput` + `close_window` 重录入库 |
| `xml-exec-guard`（首版） | 同上前台被抢 → 后重录入库 |
| `log-to-sql-clipboard`（首版） | 工具窗页签切换后输入区未就位 → 后修坐标重录入库 |
| `display-mask`（首版） | 设置页脱敏选项在首屏之下无法滚动 → 后用真实滚轮攻破重录入库 |
| `explain-history-compare`（首版） | 缺跨次 diff（结构化 EXPLAIN 未开）→ 后开设置 + 造真实差异重录入库 |
| `interceptor-inject`（前两版） | 注入通知气泡与模块对话框互相干扰 → 后用 WM_CLOSE 清气泡 + SetWindowPos 放大 + 全不选流程重录入库 |
| `datasource-badge`（首版） | 工具窗未唤出，角标变化不可见 → 后修工具窗唤起重录入库 |
| `xml-preview-rollback`（首版） | 起始帧是「SQL dialect is not configured」设置页 → 后加 prep 清场重录入库 |
