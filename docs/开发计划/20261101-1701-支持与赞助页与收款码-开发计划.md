## 一、结论与决策记录

**采用方案**：站内新建「支持与赞助」页（中英各一），内嵌微信赞赏码与支付宝收款码；Marketplace 的 Monetization 捐赠 URL 指向该页。

**为什么不选第三方**（评估留档，避免日后重问）：

| 渠道 | 费率 | 结论 |
|---|---|---|
| 爱发电 | 平台服务费 5% + 支付通道 1%（合计约 6%），最低提现 50 元（后两条为二手口径，官方协议页未列费率） | 不采用。抽成 + 提现门槛，且页面内容不受控 |
| Ko-fi | 打赏 0% 平台费（仅 Stripe/PayPal 手续费 ≈2.9%+$0.30）；商店/会员 5%；Gold ≈$12/月 | 不采用。面向英文用户、需外币收款，本站用户主体在国内 |
| 站内页 + 个人收款码 | 0（仅支付平台自身规则） | **采用**。零抽成、直达、页面可写「钱花在哪」的信任叙事 |

**同类抽样事实**（2026-11-01 实测，作为「不必随大流」的依据）：MyBatisX、MyBatisCodeHelperPro、Free MyBatis Tool 的 README 均无捐赠渠道；MyBatis Log Free 挂的是 Ko-fi；Translation（1090 万下载）用的是 Marketplace 原生 Donate 位。**同类中无一使用爱发电**。另：Marketplace API 不暴露捐赠 URL（`/api/plugins/{id}` 无相关字段），页面为 JS 渲染，故无法批量统计，只能逐个抽查。

## 二、素材前置（阻塞项）

需要站长提供两张图片，放到下列路径（本仓）：

| 路径 | 内容 | 要求 |
|---|---|---|
| `public/donate/wechat-pay.png` | 微信**赞赏码**（不是加好友码） | PNG、白底、建议 ≥400×400、无个人水印 |
| `public/donate/alipay-pay.png` | 支付宝**收款码** | 同上 |

**不可复用现有素材**：`public/wechat-qr.png` 是「加作者好友」码、`public/group-qr.png` 是交流群码，语义不同。

## 三、页面内容结构（中英同构）

新建 `about/support.md` 与 `en/about/support.md`：

1. **导语**：免费、开源（Apache-2.0）、无付费版、无广告、不收集使用数据；赞助完全自愿，不影响任何功能
2. **钱花在哪**（三条，具体到可核验的支出项）：域名与托管（Cloudflare Pages / 文档站）；演示动图录制环境（IDE 沙盒 + 多套数据库实例）；方言真机验证用的数据库与云资源（达梦 / 金仓 / OceanBase 等）
3. **微信赞赏** 与 **支付宝** 两栏并排，各放二维码 + 一句说明（建议移动端单列堆叠）
4. **海外支持者说明**：微信/支付宝需中国大陆账户；海外朋友可在 GitHub Discussions 留言或提 issue，同样是有价值的支持（链到已开启的 Discussions）
5. **不做鸣谢名单**（收款码无回调，拿不到赞助者身份）——若日后需要名单，需改用有回执的渠道

frontmatter 带 `title` 与唯一 `description`；图片 alt 中英分别写，不做关键词堆砌。

## 五、验收

1. `node scripts/check-en-parity.mjs` 中英清单一致
2. `npm run build` 退出码 0；dist 内 `about/support.html` 与 `en/about/support.html` 均含两张图路径
3. **图片必须真实就位**——图未放就构建部署会产出破图页，故实施顺序固定为「先放图 → 再改代码 → 再部署」
4. 生产复验：页面 200、两张二维码图 200、侧栏与页脚入口可点、移动端 375px 不溢出（两栏堆叠）
5. Marketplace 侧：捐赠按钮出现且跳转到本站页

## 六、风险与边界

1. **无回执**：个人收款码不提供回调，无法自动记录赞助、无法做鸣谢名单；页面文案不得承诺「名单」或「回礼」
2. **海外不可付**：英文页必须写明，避免海外用户点开后无处可付的挫败感
3. **个人收款码公开**：理论存在小额恶意试探/骚扰风险（实际概率低）；如需降低，可只放赞赏码（不含真实姓名）而非完整收款码
4. **合规**：个人收款长期大额会涉及个税，按当前量级可忽略；若未来金额显著，应改走个体户/对公渠道
5. **不承诺回报**：文案不得写成「赞助享优先支持」这类隐性承诺，与插件 Apache-2.0 免费承诺冲突
