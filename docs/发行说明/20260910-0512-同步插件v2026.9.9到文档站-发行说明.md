# 同步插件 v2026.9.9 到文档站 — 发行说明

> 发布：2026-09-10
> 范围：文档站（mybatis-plus-sql-visualizer-docs）功能内容与插件主分支 v2026.9.8 / v2026.9.9 两个发行版对齐（上一轮同步点 20260908-0836 之后）
> 红线执行：新增描述逐条对照插件 master 源码 / 语言包 / CHANGELOG 核实；v2026.9.9 发行当日追补条目（SQL 日志行号等）经 067987b 收入同版发布到 Marketplace，按已发行能力描述

## 新增内容

1. **单击预览入档**（中英 sql-log、roadmap、首页矩阵）：单击日志条目约 300ms 弹轻量预览——SQL 高亮、可直接编辑、头部「复制」按钮点击后对号反馈与「关闭」按钮、弹窗锚在被点行下方不遮挡、弹出即聚焦；双击仍开完整预览弹窗；SQL 日志 / 历史二级 / 历史工具窗三处列表一致；列表固定行高不再按内容折行
2. **SQL 日志列表行号入档**（中英 sql-log 新「条目序号」节、roadmap）：`#N` 会话内捕获序号，启动项目 / 手动清空归零，去重 / 暂停 / 过滤不占号，耗时排序保持原始捕获顺序可辨认
3. **「关闭工具窗口时停止监听」开关入档**（中英 configuration、roadmap）：日志工具窗口被关闭时自动停止捕捉（v2026.9.9 转正恢复）
4. **多租户设置四行入档**（中英 configuration SQL 预览表）：多租户注入（默认关）/ 租户列名 / 租户列默认值 / INSERT 时追加租户列（默认开、需主开关，v2026.9.9 接线生效）
5. **「自动注入源码捕获拦截器」与「设置导入导出」入档**（中英 configuration）：触发型拦截器生成开关按实际行为描述；导入 / 导出 JSON 按钮行内反馈

## 更新内容

6. **自动展开抑制解除扩展**（中英 sql-log、configuration、roadmap）：手动关窗后本会话抑制，重新开启开关、重启 IDE 或（自动监听开启时）再次运行项目后恢复
7. **自动监听被动模式**（中英 sql-log、configuration）：开启设置本身不立即开始监听，等运行项目时触发
8. **多行 JdbcTemplate 日志捕获**（中英 sql-log、roadmap）：跨行语句完整收集、字符串内方括号不误判
9. **去重判重空白规范化**（中英 sql-log、configuration）：首尾 / 连续空白差异视为重复
10. **双击预览无数据源行为**（中英 sql-log）：不再拉起 Database 工具窗抢占侧边栏，仅显式执行引导开窗
11. **插件缓存描述改全口径**（中英 configuration）：占用 + 条目数（实体反查 / 解析 / Wrapper 预览）
12. **roadmap 尾注发行收口**（中英）：「已合入 dev 分支随下个发行版提供」改为「已随 v2026.9.8 / v2026.9.9 正式发行」，挂更新日志链接
13. **首页矩阵**（homeHighlights.js）：enFeatureMatrix 补 Click Preview 行，Auto Capture 描述补多行语句与行号
