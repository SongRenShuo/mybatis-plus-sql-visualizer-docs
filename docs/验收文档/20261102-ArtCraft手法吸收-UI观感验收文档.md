## 一、这次到底改了哪些「看得见」的地方

五件事，按观感冲击从大到小：

| # | 改了什么 | 一眼能看出来的效果 |
|---|---------|------------------|
| 1 | 功能卡网格改发丝分隔 | 8 张卡从「带圆角、彼此留 32px 空隙的浮块」变成「由 1px 细线切分的整片网格」，更紧凑、更像产品文档而非营销卡片 |
| 2 | 标题里的关键词变色 | 「大幅提升您的**SQL 调试效率**」「我们为您考虑**周全**」——每节标题里有一个词被点亮，标题从陈述句变成有重音的口号 |
| 3 | 英文标题强调词改衬线斜体 | 英文站标题里的关键词是 *faster* / *scenarios* 这种斜体衬线，与中文的无衬线形成对比 |
| 4 | 首屏三级信息拉开层级 | 主按钮更大更重、次要按钮降成细边框、亮点标签加品牌色浅底、统计数字放大加竖线分隔 |
| 5 | 次要信息统一成「标签感」 | 卡片底部标签、统计数字下方说明、代码窗文件名，全部变成等宽 + 加粗 + 宽字距的小字 |

## 二、逐项对照读数

### 2.1 功能卡网格（变化最大）

| 项 | 改造前 | 改造后 |
|---|---|---|
| 卡片间距 | `gap: 32px` | `gap: 1px` |
| 容器底色 | 透明 | `#e5e7eb`（暗色 `#374151`）—— 透上来就是分隔线 |
| 卡片圆角 | `16px` | `0`（网格中圆角会露缝） |
| 卡片内边距 | `10px 29px` | `32px 28px` |
| 悬停 | 上浮 2px + 阴影 | 上浮 2px + 阴影 + 一圈描边 + `z-index: 1` |
| 网格线对比度 | — | 亮色 1.24:1、暗色 1.34:1（对卡片底）——「看得见但不抢眼」的发丝级 |

**为什么圆角归零**：1px 网格里相邻卡的圆角会在四角露出容器底色，形成四个小缺口。悬停时圆角保留，让上浮的卡有独立形体。

**为什么加 `z-index`**：悬停上浮 2px 会压住相邻卡的 1px 边线，抬到上一层后阴影与边线都完整。

### 2.2 标题强调词

改造前：全站标题纯无衬线，一个颜色。

改造后：

| 区块 | 标题 | 强调词 |
|------|------|--------|
| 核心能力 | 大幅提升您的 SQL 调试效率 | `SQL 调试效率` |
| 预览能力 | 多方言、多场景全覆盖 | `全覆盖` |
| 更多特性 | 我们为您考虑周全 | `周全` |
| 免费下载 | 完全免费 | `免费` |
| 数据事实 | 开发者在怎么用它 | `怎么用它`（原有） |
| 开源免费 | 完全免费基于 Apache-2.0 协议 | `基于 Apache-2.0 协议`（原有，渐变改纯色） |
| 开始使用 | 准备好告别繁琐的 SQL 调试方式了吗？ | `SQL 调试方式了吗？`（原有） |
| 首屏 | 服务未启，SQL 先知 | `SQL 先知`（原有） |

**英文侧的差异**（仅英文站生效）：

| 项 | 中文 | 英文 |
|---|---|---|
| 强调词字体 | 无衬线（`Punctuation SC`） | 衬线 Georgia |
| 字形 | 正常 | *斜体* |
| 字重 | 600 | 400 |

中文没有斜体字形（浏览器只能合成倾斜，观感差），所以中文侧只用颜色强调。

### 2.3 首屏三级信息

| 元素 | 改造前 | 改造后 |
|---|---|---|
| 主按钮内边距 | `12px 24px` | `14px 28px` |
| 主按钮字重/字号 | 600 / 14px | 700 / 15px |
| 次按钮边框 | `2px` 品牌色 | `1px` 中性色 |
| 次按钮文字色 | 品牌色 | 正文色 |
| 亮点标签底色 | `#f9fafb`（灰） | 品牌色 8% 浅底 |
| 亮点标签边框 | `1px` 中性 | `1px` 品牌色 28% 混色 |
| 统计数字字号 | 24px | 28px |
| 统计数字 | 无等宽数字 | `tabular-nums`（数字不等宽会让竖线抖动） |
| 统计项之间 | 无分隔 | 1px 发丝竖线 |
| 三级间距 | 统一 1.5rem | CTA↔标签 1.75rem、标签↔数据 2.5rem |

主按钮 hover 从「只加一层几乎看不见的阴影」改为「底色加深 + 投影」双通道，暗色下也有反馈。

### 2.4 次要信息统一（`.hud-label`）

改造前同类信息散在 4 种正字距（`0.2em` / `0.12em` / `0.08em` / `0.01em`）、2 种 px 字距、字号 0.8125rem 到 0.9375rem 不等，同一屏内肉眼可辨差异。

改造后统一为 17 处：

| 参数 | 值 |
|---|---|
| 字号 | `0.75rem`（12px，代码窗标签 12px / 事实出处 13px 因原样式而异） |
| 字重 | `700`（统计数字下方标签原为 500，保留） |
| 字距 | `0.12em`（标签行单独收到 `0.08em`，见下） |
| 字体 | 等宽 `ui-monospace` 系 |
| 颜色 | `--text-secondary` |
| 大写 | **不用** `text-transform`（见下） |

落点：功能卡标签 ×9、事实出处 ×3、统计数字标签 ×3、代码窗文件名 ×2。

**两处刻意的例外**：

1. **不用 `text-transform: uppercase`**。实测会把「JPA / Hibernate」写成「JPA / HIBERNATE」、「Java 开发工程师」写成「JAVA 开发工程师」——品牌名与中英混排身份被无谓改写。字距 + 等宽 + 字重已足够承担「这是标签」的信号。
2. **标签行字距收到 `0.08em`**。`0.12em` 会把最长的一条标签（「CRUD 一键生成 · 真实 EXPLAIN · MCP 十一工具」）撑到换行，末行只剩一个「具」字。实测 `0.08em` 是不换行的最大档。

### 2.5 标题字重与字距

| 项 | 改造前 | 改造后 |
|---|---|---|
| 字重 | `bold`(700) ×3、`700` ×3、`800` ×2 | 统一 `600` |
| 字距 | `normal` | `-0.02em` |
| 行高 | 1.1 / 1.2 / 1.25 三种 | 统一 `1.15` |

字重 600 是实测选定：做了 Chrome headless 对照实验（400/500/600/700 四档），四档全部可辨，取 600 介于「比 bold 轻」与「仍清晰」之间。字距 `-0.02em` 而非目标页的 `-0.035em`，后者对长标题有轻微粘连感。

## 三、暗色模式

两模式均实测，无遗漏：

| 项 | 亮色 | 暗色 |
|---|---|---|
| 网格线 | `#e5e7eb` | `#374151` |
| 网格线对卡片对比度 | 1.24:1 | 1.34:1 |
| 标签色对卡片对比度 | 4.83:1 | 5.44:1 |
| 强调色 | `rgba(46,106,224,.84)` | 同（品牌色两模式一致） |

标签对比度两模式均 ≥4.5:1，满足正文可读门槛。

## 五、过程中发现并修掉的回归

这些都是改造自己引入的，用基线对照实测发现：

| 回归 | 基线 | 未修时 | 根因 | 修法 |
|------|------|-------|------|------|
| 英文标签换行 | 全 1 行 | 9 张中 6 张 2 行 | 等宽字体每字符同宽，英文标签比中文长一倍以上 | 英文任何视口用比例字体 |
| 中文窄屏标签换行 | 全 1 行 | 9 张中 5 张 2 行 | 等宽 + `0.08em` 在单列窄卡下撑破 | 仅 `max-width: 767px` 下中文换比例字体 |
| 品牌名被改写 | — | 「JPA / HIBERNATE」 | `text-transform: uppercase` | 移除该属性 |
| 价格区说明被误套 HUD | — | 完整句子被当成标签，且丢了字号颜色 | 判据应用过宽 | 撤销并还原原样式 |

英文那处的对照做了公平处理：把当前卡宽压到与基线相同（306px）再测，等宽 2 行、比例 1 行，确认是字体而非卡宽。

## 六、合并 master 后的额外处理

基线对齐时把 `master`（67 个提交）合入，出现两处冲突：

1. **`Testimonials.vue` 结构性冲突**：master 已把「用户评价」整个重写为「数据事实」（`fact-*` 结构 + `useFacts` 实时数据）。我加在旧结构上的 `.testimonial-role` 已无落点，采用 master 新结构。
2. **计划文档 add/add 冲突**：dev 版是 230 行旧版（缺全部修正与实施记录），保留 424 行版本。

合并后发现 master 新结构的 `.fact-label`（数字出处说明，如「JetBrains Marketplace 公开数据 · 截至…」）是 T2 统一时漏掉的 meta 行，已补 `.hud-label`。`.fact-detail`（正文说明）与 `.fact-link`（CTA 链接）不是 meta，未加。
