# 文档站体验优化 发行说明

- 发布时间：2026-09-03 00:26
- 关联计划：`docs/开发计划/20260902-2347-文档站体验优化-开发计划.md`
- 状态：T1~T8、T11 已实施，T9/T10/T12/T13 待后续排期

## 本次上线内容

### 演示素材接真（T1）

- `GifPlayer` 组件新增 `video` 属性，支持 mp4 演示视频（muted / loop / autoplay / 点击暂停），为后续真录屏预留
- 功能页占位 SVG 换成插件真实功能截图（wrapper-preview / xml-preview / annotation-preview / sql-log / sql-to-java 五页，中英同步），截图取自插件仓库 `docs/images/`
- batch-operation、code-completion 两页仍为占位 SVG，待真机录屏后替换
- 首页 FeatureAlternate 区块原引用 32 字节视频占位文件导致渲染空白，改为真实截图；DocsShowcase 同样处理

### 首页 CTA 强化（T2）

- Hero 主按钮改为「在 Marketplace 中安装」，副按钮改为「下载离线包」指向 Gitee Releases
- Hero 新增元信息文字行「最新版本 v2026.9.2 · 支持 IDEA 2024.3+ · Apache-2.0 开源」，纯文本样式与正文字体一致；版本号通过新增 `usePluginVersion` composable 从 `/api/changelog` 实时获取，失败静默降级静态兜底值
- 导航栏新增 Gitee 图标外链

### 社交分享图（T3）

- 新增 `public/og-image.png`（1200×630，由更名后的 og-image.svg 无头浏览器渲染导出），config head 的 og:image / twitter:image 指向 PNG 并补尺寸与 og:url；SVG 源文件标题同步更名 SQL Visualizer

### 暗色模式（T4）

- `appearance` 从 `'light'` 改为 `'switch'`：支持亮暗切换，默认亮色（不跟随系统暗色偏好）
- 首页自定义导航新增主题切换按钮（VitePress `useData().isDark`），补齐首页此前无切换入口的问题
- FeaturesGrid 六色图标芯片补 `.dark` 覆盖（半透明色调），文档区内页由 VitePress 原生支持，Testimonials / WelfareCard 已有暗色规则

### SEO 套件（T5 + T6）

- `transformHead` 按页面注入 canonical 与 zh-CN / en-US / x-default 互指 hreflang
- head 新增 SoftwareApplication JSON-LD（分类 / 平台 / 免费价格）
- 接入 `vitepress-plugin-llms`，构建产物自动生成 `llms.txt` / `llms-full.txt`；changelog 页补 frontmatter title 消除 Untitled 条目

### 内容补强（T7 + T8）

- 新增指南页（中英同步）：`guide/comparison`（方案对比）、`guide/shortcuts`（快捷键速查）、`guide/compatibility`（版本兼容矩阵），全部进 sidebar
- 自定义 404 页（not-found slot）：大号 404 + 返回首页 / 快速开始按钮
- 英文区搜索弹窗补翻译；新增 `scripts/check-en-parity.mjs` 中英页面清单校验脚本（当前输出一致）

### 更新日志 RSS（T11）

- 新增 CF Function `functions/feed.xml.js`，`/feed.xml` 输出最近 20 个版本的 RSS，缓存 1 小时

## 遗留事项

- batch-operation、code-completion 真机录屏素材待补（补齐后功能页 `GifPlayer` 传 `video` 属性即可）
- T9 Cloudflare Web Analytics 需控制台操作，T10 在线交互演示、T12 页面反馈、T13 媒体优化按计划批次三排期
- llms.txt 目前包含 docs/ 内部开发文档（本就公开构建），如需精简可后续评估 `srcExclude`
- deploy 前建议用 `wrangler pages dev` 本地过一遍 `/api/changelog` 与 `/feed.xml`
