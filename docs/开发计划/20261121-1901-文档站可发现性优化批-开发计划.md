# 文档站可发现性优化批 开发计划

## 背景

主控已完成外部调研与决策，本计划直接引用其结论：

- 文档站 sql-visualizer.jvtools.cn 技术面零硬伤：title / meta description / OG 全套 / canonical / lang / 两段 JSON-LD（WebSite + SoftwareApplication）/ sitemap.xml / robots.txt 全部就位，Google 已收录 10+ 页。短板在站外（外链与内容生态为零），本批只做技术面与站内引导的克制增量，不追求全站改动。
- 插件端 2026-11-21 已拍板：Marketplace 展示名与包内 plugin.xml `<name>` 更名为 **MyBatis SQL Visualizer**（B1 案，包内已提交 acd4c8bdb，后台待改）。品牌词「SQL Visualizer」保留、界面内品牌文案不改。文档站同样不做全站品牌改名，只在实体 / 元数据层面引入全名。
- 官方 SEO 结论：描述可做关键词设计但禁止堆砌；GitHub star=0 是浏览器侧最弱信号，放数字徽章反而难看；Marketplace 评分恒零是信任短板。
- 评分引导合规口径 V47：不承诺互惠、不筛选情绪、不代填内容，只说「真实体验」，话术 ≤60 字（沿用插件仓 `docs/内容营销/W1三件文案与Marketplace首屏稿-20261106-A03A04.md` 的双语定稿）。

## 基线（技术面检查结论，2026-11-21 merge 后复核）

- `.vitepress/config.mts` 两段 JSON-LD：WebSite `name=SQL Visualizer`；SoftwareApplication `name=SQL Visualizer`，无 `alternateName`，`softwareVersion` 由构建期脚本注入。
- 全局 head og:title / og:site_name 均为 `SQL Visualizer`；中文首页 title `SQL Visualizer | IntelliJ IDEA SQL 预览与调试插件`（品牌资产，不动）；英文站 title 与英文首页 title 均为 `SQL Visualizer`。
- 首页为自定义 CoolHome 组件树（`layout: false`），GitHub 仓库链接已存在于导航栏（桌面 + 移动）与福利卡，但无 Star 引导文案；首页页脚只有一行版权文字。
- 反馈页（`/about/feedback` 与 `/en/about/feedback`，同一 FeedbackPage 组件）无 Marketplace 评分入口。
- 生态表述核查：站内「官方」字样全部指向数据库厂商官方镜像 / iBatis 官方引擎语义 / 各方言官方文档，属验证层级描述，非产品背书；`guide/compatibility.md` 的 MyBatis-Plus 链接与功能兼容表是兼容性描述，按口径不算背书；about 页自我定位为独立开发者项目。未发现易混淆为官方背书的表述，本批不为兼容性描述加过度免责，仅在 about 页补一句非官方定位澄清（中英）。
- sitemap / robots：robots.txt 已带 Sitemap 行；VitePress sitemap 按路由自动生成，本批不新增页面（只改既有页），sitemap 无需改动。

## 改动清单

1. 实体名对齐（a）
   - `config.mts` SoftwareApplication：`name` → `MyBatis SQL Visualizer`，新增 `alternateName: ["SQL Visualizer", "MyBatis-Plus SQL Visualizer"]`。
   - `config.mts` en locale `title` → `MyBatis SQL Visualizer`（英文页 `<title>` 后缀随之带上全名）；`en/index.md` title 自然带入全名。
   - og:title / og:site_name / WebSite JSON-LD / 中文首页 title / 全站中文 brand 文案一律不动（品牌资产，保守评估）。
2. GitHub Star 引导（b）
   - 首页页脚（CoolHome.vue `mp-footer`）加一行合规引导 + GitHub 仓库链接（github.com/SongRenShuo/mybatis-plus-sql-visualizer）；文案不承诺利益（「觉得有用的话，欢迎给个 Star」风格），中英双语走 homeContent.js；不用 shields 徽章。
3. Marketplace 评分入口（c）
   - FeedbackPage.vue 在订阅卡上方加一条评分引导（链接 plugins.jetbrains.com/plugin/33633-mybatis-sql-visualizer/reviews），文案沿用 W1 双语定稿（zh 58 字 / en 11 词，V47 自查通过），i18n 键进 feedback/i18n.ts，站内语言跟随页面。
4. 生态表述澄清（d）
   - `about/index.md` 与 `en/about/index.md` 作者段落补一句「社区项目、与 MyBatis-Plus / JetBrains 无隶属关系」的定位澄清；兼容性描述不加免责。
5. 收录面核对（e）
   - 无新增页面，sitemap/robots 复核后无改动（若实施中发现新增页面则补 sitemap，实际不适用）。
