### 2.1 数据与后端（admin 仓）

| 项 | 落地 |
|----|------|
| 迁移 | `migrations/0022_bounty.sql`：`bb_submissions`、`bb_attachments`、`bb_status_logs` + 索引 + 默认 `bounty.policy`（`enabled=false`、`maxReward=1888`、四档 1200–1888/800–1200/400–800/100–300） |
| 公开接口 | `GET /api/v1/bounty/policy`、`POST /submissions`、`POST /lookup`、`GET /stats` |
| 管理接口 | `/api/v1/admin/bounty` 下列表/详情/start/review/reopen/withdraw/payout/revoke-approval/link-post/promote/policy GET+PUT/stats/export |
| 状态机 | 1 待审核 → 2 审核中 → 3 待发放 → 4 已发放；5 未通过 / 6 重复 / 7 已撤回；条件更新冲突 409 |
| 权限 | 审核/状态操作/关联/转帖/导出 `requireEdit`；发放/撤销通过/策略 PUT `requireSuperAdmin` |
| 通知 | 管理员 `bounty_notify` 聚合；提交人 `bounty_review`/`bounty_payout` 邮件；`siteBrand` 分站品牌 |
| 清理 | 未通过/重复/撤回 90 天、已发放 365 天、软删 90 天清联系方式；附件失败按 `contact_purged=1` 反查重试 |
| 审计 | 10 个固定 action + `bounty_cleanup`，写 `sys_audit_logs`；状态变化另写 `bb_status_logs` |

### 2.2 管理后台（admin 仓）

- 路由 `#/bounty`，侧栏「Bug 悬赏」；支持 `#/bounty?no=BB-0001` 深链。
- 列表：状态/有效性/等级/站点/关键词/日期/排序筛选；疑似重复、安全类、联系方式已清除标记。
- 详情：报告正文、环境、联系方式、附件、关联 FR、状态时间线、审核与发放留痕。
- 审核：有效性/终评/金额（元转分，建议值 + 区间 + 上限 ¥18.88）/审核说明/内部备注；保存前二次确认。
- 发放：仅超管，方式/单号/备注；策略弹窗仅超管。
- 附件：复用 T8 的 `useAttachmentBlobs` / `/admin/attachments/*`，不新增端点。
- 通知中心补 `bounty_notify` / `bounty_review` / `bounty_payout` 三种类型。

### 2.3 官网（docs 仓）

| 项 | 落地 |
|----|------|
| 页面 | `/about/bounty`、`/en/about/bounty`，`layout: page`、`sidebar: false` |
| 内容 | hero、统计、四档金额表、流程、表单、查询、规则与边界、FAQ（`::: details`） |
| 表单 | 邮箱必填只在悬赏表单；标题/描述/步骤长度校验；附件最多 3 个；蜜罐；安全类勾选；提交前 trim；上传中禁提交；上传失败透传后端 message；object URL 预览 |
| 查询 | 编号 + 邮箱 POST；错误统一「记录不存在或邮箱不匹配」；429/网络异常单独提示 |
| 导航 | 中文「Bug 悬赏」在「需求池」后；英文「Bug Bounty」在 Feedback 后；关于页联系方式表各加一行 |

## 五、手工验收步骤（待用户真机走查）

以下为计划 §14.3 的验收清单，自动化无法覆盖，需部署或本地正常 Worker 后逐项执行：

1. 官网 `/about/bounty` 中英文各打开一次：等级表金额与策略一致（上限 ¥18.88）；`enabled=false` 时表单禁用、显示暂停。
2. 悬赏表单：空邮箱不能提交；格式错误提示；正常提交返回 `BB-0001`；附件 3 个上限；375px 移动端可用。
3. 需求池联动：Bug 提交时邮箱仍为选填；勾选「同时申请悬赏」→ 成功 toast 出现「继续申请悬赏」链接（15s）→ 同标签页跳转悬赏页，`postNo`/标题已带入、邮箱从 `sessionStorage` 带入且 URL 不含邮箱；悬赏表单邮箱必填。
4. 查询：正确编号+邮箱能看到状态时间线；错误邮箱 404；已发放记录显示金额但不显示单号。
5. 管理后台：只读管理员看不到写按钮；可编辑管理员能审核；超管能发放；状态冲突提示；金额超过 ¥18.88 被拒；策略修改后公开页金额表刷新。
6. 通知：管理员收到新提交聚合推送；提交人收到审核/发放邮件；QQ 邮箱中链接以明文可复制形式展示。
7. 转公开帖：生成的 `fb_posts` 默认隐藏、`source=bounty`、`extra_data` 含 `BB-xxxx`、正文不含邮箱与金额；公开后需求池列表可见。
8. 附件：管理端图片能预览、非图片能下载；未登录直接访问 `/admin/attachments/*` 401。
