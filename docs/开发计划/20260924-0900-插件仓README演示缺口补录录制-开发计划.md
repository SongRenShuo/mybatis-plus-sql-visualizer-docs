## 五、分镜草案（开录前按现场构图微调，微调不回写本计划）

- **R1 聚焦页签（10~15s）**：日志列表若干条目 → 右键某条「聚焦调用方方法」→ 生成聚焦页签、列表只剩该方法区间条目、显示范围外计数 → 时间够再补「按请求聚焦」→ 关闭页签恢复。
- **R2 XML 回滚（10~14s）**：mapper XML 语句 gutter 预览 INSERT → 右上「更多」菜单 → 首项「回滚 SQL」→ 弹窗展示逆向 DELETE（整行等值谓词）→ 一键复制。
- **E1 执行 SQL（14~20s）**：Wrapper 预览弹窗 → 数据源下拉选 demo 源 → 执行 → 结果表格出现并滚动几行 → 切「执行计划」tab 看 EXPLAIN → 换一条带错列名的语句执行 → 错误条 + 「定位到出错语句」→ 点击跳回源码。无界写确认浮层如出现按实录取舍，不摆拍。
- **J1 JOIN 关系图（8~12s）**：MPJ 联表 Wrapper 预览 → 「关系图」tab → 两表节点 + JOIN 连线自适应居中 → 滚轮缩放/拖拽一下 →（可选）导出 PNG 对话框一闪。
