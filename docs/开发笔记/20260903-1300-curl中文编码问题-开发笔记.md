# curl 发送中文数据的编码问题

- 记录时间：2026-09-03 13:00
- 项目：sql-visualizer-admin（Cloudflare Workers + D1 方案）

## 问题描述

使用 curl 发送包含中文的 JSON 数据时，后端接收到的数据是乱码。

```bash
curl -X POST https://api.example.com/posts \
  -H "Content-Type: application/json" \
  -d '{"title":"测试反馈","description":"中文内容"}'
```

后端存储后变成：`���Է�������`

## 根本原因

Windows 下 curl 默认使用 **GBK 编码**发送请求体，而不是 UTF-8。而服务器期望接收 UTF-8 编码的数据，导致中文字符被错误解析。

### 编码转换过程

```
原始文本：测试反馈
GBK 字节：B2 E2 CA D4 B7 B4 C0 A1
服务器按 UTF-8 解析：���Է�������（乱码）
```

## 解决方案

### 方案1：使用 `--data-binary` + 文件（推荐）

```bash
# 1. 将 JSON 写入 UTF-8 编码的文件
echo {"title":"测试反馈","description":"中文内容"} > data.json

# 2. 使用 --data-binary 发送（不转换编码）
curl -X POST https://api.example.com/posts \
  -H "Content-Type: application/json; charset=utf-8" \
  --data-binary @data.json
```

### 方案2：使用 Unicode 转义

```bash
curl -X POST https://api.example.com/posts \
  -H "Content-Type: application/json" \
  -d '{"title":"\u6d4b\u8bd5\u53cd\u9988","description":"\u4e2d\u6587\u5185\u5bb9"}'
```

常用中文 Unicode 转义：
| 字符 | Unicode 转义 |
|------|-------------|
| 测试 | `\u6d4b\u8bd5` |
| 反馈 | `\u53cd\u9988` |
| 中文 | `\u4e2d\u6587` |
| 内容 | `\u5185\u5bb9` |

### 方案3：设置 Windows 控制台为 UTF-8

```bash
# 在 cmd 中
chcp 65001

# 在 PowerShell 中
[Console]::OutputEncoding = [System.Text.Encoding]::UTF8
```

然后正常使用 curl，但**不推荐**，因为可能影响其他命令行工具。

### 方案4：使用 PowerShell 的 Invoke-RestMethod

```powershell
$body = @{
    title = "测试反馈"
    description = "中文内容"
} | ConvertTo-Json

Invoke-RestMethod -Uri "https://api.example.com/posts" `
  -Method POST `
  -ContentType "application/json; charset=utf-8" `
  -Body ([System.Text.Encoding]::UTF8.GetBytes($body))
```

## 验证方法

```bash
# 检查存储的数据是否正确
curl https://api.example.com/posts/FR-0001
```

如果返回的 `title` 字段显示正确的中文，说明编码正确。

## 经验总结

1. **Windows curl 默认使用 GBK**，发送中文时必须使用 `--data-binary` 或 Unicode 转义
2. **服务器始终使用 UTF-8**，不要尝试在服务器端做编码转换
3. **Python requests 库没有这个问题**，它默认使用 UTF-8
4. **Postman/Insomnia 等工具也没有这个问题**，它们默认使用 UTF-8

## 推荐做法

对于需要频繁测试中文 API 的场景，建议：
- 使用 **Postman** 或 **Insomnia** 等 API 测试工具
- 或者使用 **Python requests** 编写测试脚本
- 避免使用 curl 发送中文数据
